# 학교예산 한눈에 보기

학교 예산 업무를 더 빠르고 정확하게 처리할 수 있도록 돕는 웹 도구입니다.

- 운영 주소: https://school-budget-portal.vercel.app/
- 운영 주소: https://yegamday.vercel.app/

## 주요 기능

- 예산안건 설명서 자동화
- 본예산 편성 Excel 기초자료만들기
- 본예산 일반업무추진비 편성 비율 자동계산
- 2026학년도 예산편성 지침 PDF 검색 및 미리보기
- 성립전예산 임시저장·자동점검·기안문 및 Excel·한글·PDF 생성
- 결산설명서 자동화 및 에듀파인 102-2 집행실적 기반 추경 기초자료 생성
- 원가통계비목 20개와 비목별 동적 설명 제공
- 예산웹툰 제공
- 예산 및 서울시교육청 관련사이트 제공

## 메뉴별 사용 안내

### 홈

서비스의 첫 화면입니다. 필요한 업무를 선택하거나 상단 검색을 통해 메뉴로 이동합니다.

### 학교별 예산 분석

학교별 세입·세출 결산과 예산 사용 내역을 분석할 때 사용합니다. 분석 대상 학교와 자료를 선택한 뒤 결과를 확인하세요.

### 예산 업무

- **성립전예산요구서작성(사업담당자용)**: 재원 유형과 사업 기본정보, 산출내역을 입력합니다. 자동점검 결과를 확인한 뒤 기안문과 제공되는 형식의 파일을 생성합니다.
- **본예산 편성 기초자료 만들기**: 에듀파인에서 내려받은 세입·세출 예산서 Excel 파일을 불러옵니다. 분석 결과를 표로 확인하고 결과 파일을 내려받습니다.
- **예산 편성 확인(업무추진비 3% 편성 확인)**: 세입예산명세서와 세출예산명세서가 포함된 Excel 파일을 선택합니다. 세입 기준금액, 일반업무추진비 합계와 편성 비율을 자동 계산합니다.
- **추경예산자료 만들기**: 에듀파인 집행실적 102-2 Excel 파일을 불러온 뒤 집행예정액과 추경안을 입력합니다. 추경 가능금액을 검토하고 결과 Excel을 내려받습니다.
- **안건설명서 만들기**: 세입·세출 예산총괄표를 불러와 학교운영위원회용 예산안건 설명서를 작성합니다.
- **결산 설명서 만들기**: 결산 총괄표를 바탕으로 주요 증감과 사업 내용을 정리한 결산 설명서를 만듭니다.

### 예산 자료실

예산편성 기본지침을 검색하고, 필요한 PDF·Excel 업무자료를 내려받습니다.

### 참고사이트

교육청, 열린재정, 에듀파인 등 예산 업무에 필요한 외부 사이트로 이동합니다.

### 동영상 안내

학교회계와 예산관리 관련 교육영상을 확인합니다.

### 예산 웹툰

학교예산 업무를 쉽게 설명한 웹툰을 봅니다.

### 학교예산 질의응답

학교예산 관련 질문을 입력하고 안내를 받을 수 있는 질의응답 서비스로 이동합니다.

## 본예산 파일 분석 안내

- K-에듀파인에서 출력한 XLS, XLSX 파일 1개를 지원합니다.
- 파일 읽기, 계산은 모두 브라우저에서 처리합니다.
- 원본 파일은 서버에 전송하거나 저장하지 않으며, 분석 결과만 현재 브라우저의 로컬 저장소에 보관됩니다.

## 참고

- 최초 OCR 사용 시 Tesseract worker·core·한국어/영어 언어 데이터가 외부 저장소에서 내려받아지므로 인터넷 연결이 필요합니다. 원본 PDF와 페이지 이미지는 외부로 업로드되지 않습니다.
- `node_modules`는 포함하지 않았으므로 `npm install`로 복원합니다.
- `public/guidelines` 폴더에 실제 지침 PDF가 포함되어 있습니다.

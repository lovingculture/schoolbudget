실행 방법
1. 이 폴더에서 터미널을 엽니다.
2. npm install
3. npm run dev

검증 방법
- 테스트: npm run test:run
- 운영 빌드: npm run build

본예산 파일 분석 안내
- 지원 형식: K-에듀파인에서 출력한 PDF, XLS, XLSX 파일 1개
- 파일 읽기, PDF 문자 추출, 스캔 PDF OCR, 계산은 모두 브라우저 안에서만 처리됩니다.
- 원본 파일은 서버로 전송하거나 저장하지 않습니다. 분석 결과만 현재 브라우저의 로컬 저장소에 보관되어 새로고침 후 복원됩니다.
- 다른 파일 분석을 선택하면 저장된 결과가 지워집니다.
- 스캔 PDF는 한글 OCR 준비와 페이지 인식에 시간이 걸릴 수 있습니다. 진행률을 확인할 수 있고 분석 중 취소할 수 있습니다.
- 스캔 PDF에서 필수 예산 구역은 확인되지만 금액 인식 신뢰도가 낮으면 분석을 중단하지 않고 `확인 필요` 결과와 원본 페이지·행 근거를 표시합니다. 이 경우 금액을 임의로 확정하지 않으므로 반드시 원본과 대조하세요.
- 이미지형 PDF에서 OCR을 처음 사용할 때 Tesseract worker, core, 한국어·영어 언어 데이터가 외부 저장소에서 다운로드됩니다. 따라서 인터넷 연결과 배포 환경의 CSP 및 네트워크 설정에서 해당 외부 자산 요청을 허용해야 합니다. 이 과정에서도 원본 PDF와 페이지 이미지는 외부로 업로드되지 않습니다.
- 세입 기준금액 = 세입예산총액 - (목적사업비전입금 + 수익자부담수입)
- 편성 비율 = 일반업무추진비 합계 ÷ 세입 기준금액 × 100

테스트 자료 안내
- 일부 테스트는 개발 당시 업로드한 실제 에듀파인 102-2 Excel 원본을 참조합니다.
- 개인정보 보호를 위해 해당 사용자 원본은 ZIP에 포함하지 않았습니다.
- 원본이 없는 환경에서는 실제 파일 기반 테스트의 파일 없음(ENOENT) 결과와 나머지 테스트 결과를 구분해서 확인하십시오. 전체 테스트는 npm run test:run, 운영 빌드는 npm run build로 현재 상태를 검증할 수 있습니다.

참고
- node_modules는 용량이 크므로 ZIP에서 제외했습니다. npm install로 복원됩니다.
- Vercel 프로젝트 연결정보(.vercel)는 개인정보 및 오배포 방지를 위해 제외했습니다.
- public/guidelines 폴더에 실제 지침 PDF가 포함되어 있습니다.
- dist 폴더에는 현재 운영 배포와 일치하는 빌드 결과물이 포함되어 있습니다.

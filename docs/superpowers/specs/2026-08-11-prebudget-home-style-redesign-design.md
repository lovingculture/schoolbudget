# 성립전예산 홈 일치형 화면 개편 설계

## 목표

성립전예산의 예시 선택부터 입력, 자동점검, 기안문 미리보기와 다운로드까지 전체 화면을 홈페이지와 같은 네이비·하늘색·민트색 디자인으로 통일한다. 기존 데이터·계산·저장·문서 생성 기능은 그대로 유지하고, 초보 사용자가 예시 선택과 다음 작업을 쉽게 찾도록 시각적 순서를 개선한다.

## 디자인 방향

선택한 시안은 `A. 홈 화면 일치형`이다.

- 기본 글꼴: `Noto Sans KR`
- 네이비: `#14334E`
- 파랑: `#188BC1`
- 청록: `#1596A3`
- 접근성용 진한 청록 글자: `#0B5F66`
- 연한 하늘색: `#EEF8FC`
- 연한 민트색: `#EFFAF7`
- 기본 카드: 흰색
- 카드 테두리: `#D8E5EB`
- 주요 버튼: 접근성 대비를 충족하는 진한 파랑→청록 그라데이션
- 삭제·오류처럼 주의가 필요한 요소에만 코랄 계열을 제한적으로 사용한다.

제목·설명·버튼 문구는 화면 구조와 분리해 후속 작업에서 수정할 수 있게 한다. 이번 범위에서는 사용자가 별도로 요청하지 않은 문구와 문서 본문을 변경하지 않는다.

## 전체 화면 구조

성립전예산 작성 화면은 다음 순서로 구성한다.

1. 상단 소개 영역
2. 4단계 진행 표시
3. 예시에서 시작하기 안내
4. 기본정보 입력 카드
5. 예산항목 입력 카드
6. 자동점검 결과와 저장·생성 작업
7. 기안문 미리보기와 파일 다운로드

### 상단 소개 영역

- 홈페이지 히어로와 같은 하늘색→민트색 그라데이션을 사용한다.
- `성립전예산 요구서 작성` 제목과 현재 안내 문구를 표시한다.
- 이전에 제공된 서울시교육청 캐릭터 AI·매뉴얼에서 추출한 공식 `prebudget-writing.png` 자라나 포즈를 오른쪽에 배치한다.
- 캐릭터의 색·비율·선 형태를 변형하지 않으며 PC에서는 180~220px, 좁은 화면에서는 제목 아래 중앙에 110~130px로 축소한다.
- 캐릭터는 이 상단 영역에 한 번만 사용해 예시·입력 카드의 집중도를 유지한다.
- 예시 선택 진입 버튼은 소개 영역 또는 바로 아래 안내 카드에서 가장 먼저 찾을 수 있게 한다.
- 장식 때문에 입력 영역이 지나치게 아래로 밀리지 않도록 높이를 제한한다.

### 단계 표시

다음 4단계를 유지한다.

```text
1 기본정보 → 2 예산항목 → 3 자동점검 → 4 미리보기·생성
```

- 현재 단계는 네이비 또는 진한 청록 배경과 흰색 글자로 표시한다.
- 아직 도달하지 않은 단계는 연한 하늘색 배경과 진한 글자로 표시한다.
- 문서가 생성되면 자동점검과 미리보기·생성 단계를 완료 상태로 표시한다.
- 단계 표시는 기존 상태를 읽기만 하며 작성 데이터를 수정하지 않는다.

## 예시 선택 화면

- 재원구분 안내는 홈의 업무 카드와 같은 흰색 둥근 카드로 표시한다.
- 목적사업비·보조금·수익자부담경비의 구분은 텍스트와 색상 강조를 함께 사용하며 색상만으로 구분하지 않는다.
- 선택한 재원구분은 청록색 강조 배경·테두리와 명확한 선택 상태로 표시한다.
- 예시 검색·필터와 기존 16개 예시 데이터 및 적용 동작은 그대로 유지한다.
- 예시 카드는 사업명, 재원구분, 핵심 설명과 `이 예시로 작성하기` 행동이 한눈에 보이도록 정리한다.
- 예시를 선택하면 입력값을 바로 덮어쓰지 않고 상세 미리보기를 먼저 표시한다.
- 미리보기에는 재원구분, 문서 제목, 부서·담당자 예시, 단위사업·세부사업·세부항목, 원가통계비목, 산출내역, 예시 금액, 기안문 예시와 확인 필요 항목을 표시한다.
- 사용자가 `이 예시로 작성하기`를 눌렀을 때만 작성 초안에 복사한다.
- 적용 후 모든 입력값과 금액을 자유롭게 수정할 수 있고, 실제 공문·금액 확인 전에는 `예시를 복사한 초안입니다` 안내를 유지한다.
- 상세 화면에서 `다른 예시 보기`로 목록에 돌아갈 수 있다.
- 실제 공문·금액 확인이 필요한 내용은 연한 노랑 또는 연한 코랄 안내 영역으로 표시한다.

## 기본정보 입력 카드

- 카드 제목과 짧은 설명을 분리해 입력 목적을 먼저 이해할 수 있게 한다.
- PC에서는 두 열, 좁은 화면에서는 한 열로 배치한다.
- 입력 글자는 16px 이상, 입력 높이는 최소 44px로 유지한다.
- 학교명·회계연도·재원구분·문서 제목·부서명·사업담당자·품의권한 부여자·관련 공문 필드를 유지한다.
- 품의권한 부여자가 공란이어도 기존 기안문 생성 규칙을 유지한다.
- 기존 임시저장값과 예시 적용값을 그대로 복원한다.

## 예산항목 입력 카드

- 각 항목은 번호, 단위사업, 세부사업, 세부항목, 원가통계비목, 산출내역, 단가·수량·횟수, 계산금액, 삭제 행동을 유지한다.
- 원가통계비목 설명은 연한 민트색 도움말 영역으로 표시한다.
- 단가·수량·횟수를 수정하면 계산금액과 전체 합계가 즉시 갱신되는 기존 동작을 유지한다.
- 항목별 계산금액은 진한 청록색으로 표시한다.
- 전체 예산요구액 합계는 별도 요약 영역에서 충분히 큰 글자로 표시한다.
- 항목 추가는 보조 버튼, 자동점검 후 생성은 주요 그라데이션 버튼, 삭제는 코랄 계열 버튼으로 구분한다.

## 자동점검과 메시지

상태별 표현을 다음처럼 통일한다.

- 정상·저장 완료: 연한 민트색 배경과 진한 녹색 글자
- 확인 필요: 연한 노랑 배경과 충분한 대비의 갈색 계열 글자
- 오류: 연한 코랄 배경과 진한 적갈색 글자

메시지는 색상뿐 아니라 제목, 아이콘 또는 상태 문구로 의미를 함께 전달한다. 기존 검증 규칙, 오류 문구, 예시 확인 필요 필드와 생성 차단 조건은 변경하지 않는다.

## 기안문 미리보기와 다운로드

- 미리보기 소개·다운로드 영역은 네이비 배경 또는 하늘색→민트색 표면으로 홈 디자인과 연결한다.
- `전체 복사`, `한글(HWPX)`, `Word`, `PDF` 버튼을 명확히 구분하고 최소 44px 클릭 영역을 유지한다.
- 성립전예산 Excel 다운로드는 추가하지 않는다.
- `.prebudget-paper`의 A4 크기, 여백, 글꼴, 문서 문안과 줄바꿈은 변경하지 않는다.
- HWPX·Word·PDF 생성기와 파일명, 다운로드 로직은 변경하지 않는다.
- 화면 디자인 규칙이 A4 문서와 내보내기 캡처에 영향을 주지 않도록 미리보기 외곽에만 새 스타일을 적용한다.

## 컴포넌트와 스타일 경계

- `PrebudgetPage`는 기존 작성 상태와 이벤트 처리 로직을 유지한다.
- 필요하면 상단 소개, 단계 표시, 예시 안내, 다운로드 헤더를 표현 전용 하위 컴포넌트로 분리한다.
- 홈 색상은 성립전 전용 CSS 변수로 연결하되 홈페이지 CSS에 직접 의존하지 않는다.
- 새 규칙은 `.prebudget-page` 또는 성립전 전용 클래스 아래로 제한한다.
- `.prebudget-paper`와 HWPX·Word·PDF 내보내기 마크업에는 일반 화면 장식 스타일을 적용하지 않는다.

## 반응형과 접근성

- 1440px PC에서는 입력 영역을 효율적으로 사용하는 두 열 배치를 유지한다.
- 390px에서는 카드·입력·버튼을 한 열로 배치하고 페이지 수준 가로 넘침이 없어야 한다.
- 모든 입력과 버튼은 키보드로 접근할 수 있어야 한다.
- 포커스 표시를 제거하지 않는다.
- 주요 버튼과 다운로드 버튼은 최소 44px 높이를 유지한다.
- 일반 크기 텍스트의 명도 대비는 WCAG AA 기준을 충족한다.
- 상태·선택·오류를 색상만으로 전달하지 않는다.

## 데이터와 기능 보존

다음 기능은 시각 개편 전후 결과가 같아야 한다.

- 16개 예시 검색·선택·적용
- 예시 선택 후 상세 미리보기와 사용자 확인을 거친 적용
- 단위사업·세부사업 연동과 세부항목 적용
- 원가통계비목 선택과 설명
- 단가×수량×횟수 계산 및 전체 합계
- 브라우저 임시저장·복원
- 자동점검과 기안문 생성
- 품의권한 부여자 공란 시 문서 항목 순서 조정
- 전체 복사
- HWPX·Word·PDF 생성과 다운로드

## 검증 기준

- 성립전예산 전체 화면에서 홈과 동일한 네이비·하늘색·민트색 체계가 일관되게 보인다.
- 예시 선택 행동이 상단에서 쉽게 발견된다.
- 공식 작성 중인 자라나 캐릭터가 상단 오른쪽에 원본 비율로 한 번만 표시된다.
- 예시 상세를 확인하기 전에는 작성 초안이 변경되지 않는다.
- 예시 선택·적용 후 기존 입력값이 정확히 채워진다.
- 금액 변경 시 항목 금액과 전체 합계가 즉시 일치한다.
- 저장·복원, 자동점검, 기안문 생성이 기존과 동일하게 동작한다.
- 실제 HWPX·Word·PDF 파일이 생성되며 기존 문서 내용과 파일 형식이 유지된다.
- A4 미리보기 크기와 문안에 일반 화면 스타일이 섞이지 않는다.
- 1440px·390px에서 페이지 가로 넘침, 입력 잘림, 겹침이 없다.
- 브라우저 콘솔 오류가 없다.
- 기존 성립전 집중 테스트와 전체 테스트·빌드가 통과한다.

## 제외 사항

- 성립전예산 문구와 기안문 본문 전면 수정
- 예시 데이터 추가·삭제
- 사업 분류와 원가통계비목 데이터 변경
- 새로운 저장 방식 또는 서버 저장
- HWPX·Word·PDF 생성 규칙 변경
- Production 배포

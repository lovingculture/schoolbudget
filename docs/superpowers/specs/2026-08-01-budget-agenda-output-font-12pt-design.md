# 예산안건설명서 출력 본문 12pt 설계

## 목적

예산안건설명서의 서술형 본문과 추경예산 편성 주요내용을 웹 미리보기 및 내려받기 문서에서 12pt로 통일한다.

## 적용 범위

- 제안이유 본문: 12pt
- 근거 본문: 12pt
- `라. 추경예산 편성 주요내용` 제목: 12pt
- 주요내용 번호와 입력 문구: 12pt
- 웹 미리보기, PDF, Word, Excel 출력에 동일 적용

## 유지 범위

- `1. 제안이유`, `2. 근거`, `3. 주요내용` 항목 제목은 현재 크기를 유지한다.
- 총 규모·세입·세출 표의 글자 크기는 변경하지 않는다.
- 입력 화면의 편집용 글자 크기는 변경하지 않는다.
- 금액, 계산, 페이지 분할, 표 구조는 변경하지 않는다.

## 단위 처리

- 웹 CSS는 `12pt`를 직접 사용한다.
- Word는 OOXML 반포인트 단위 24를 사용한다.
- Excel은 글꼴 크기 12를 사용한다.
- PDF는 웹 미리보기를 캡처하므로 웹의 12pt가 그대로 반영된다.

## 검증 및 배포

- 웹 미리보기의 전용 클래스와 출력 문서의 글꼴 크기를 검사한다.
- 예산안건설명서 관련 테스트와 전체 빌드를 실행한다.
- Vercel `school-budget-portal` 프로젝트에 Preview로만 배포한다.
- 운영 배포와 Preview 운영 승격은 수행하지 않는다.

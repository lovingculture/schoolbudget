# 추경자료 매크로 포함 Excel 설계

## 목표

`집행실적으로 추경자료 만들기`에서 동일한 입력 자료를 일반 `.xlsx`와 버튼 포함 `.xlsm` 두 형식으로 선택해 내려받는다. 일반 파일은 현재 생성 방식을 유지하고, 버튼 포함 파일은 기준 파일 `집행실적정리용엑셀 확정본(2).xlsm`을 바탕으로 생성한다. 두 파일 모두 사용자가 업로드한 에듀파인 102-2 자료와 웹 화면에서 입력한 추경 값을 동일하게 반영한다.

## 원인과 변경 방향

현재 ExcelJS 일반 다운로드는 계속 제공한다. 매크로 다운로드는 기준 `.xlsm` 패키지를 그대로 복제한 뒤 데이터가 들어가는 워크시트 XML과 관련 범위만 갱신한다. 매크로와 버튼이 들어 있는 패키지 구성요소는 재생성하지 않고 원본 그대로 유지한다.

## 두 가지 출력 파일

- 일반 Excel: `{연도}_{학교명}_추경검토자료_일반.xlsx`
- 버튼 포함 Excel: `{연도}_{학교명}_추경검토자료_버튼포함.xlsm`
- 화면에는 `일반 Excel 다운로드`와 `버튼 포함 Excel 다운로드` 버튼을 나란히 표시한다.
- 각 버튼은 생성 중에 독립적으로 비활성화되며 해당 형식의 생성 상태를 표시한다.
- 기준 시트 순서: `Sheet1`, `불러온원본`, `추경검토`, `정리본`, `단위사업별집계`
- `Sheet1`은 VBA가 참조할 가능성이 있으므로 제거하지 않는다.
- Excel에서 처음 열 때 사용자가 `콘텐츠 사용` 또는 `매크로 사용`을 눌러야 버튼이 동작한다.

## 보존 대상

- `xl/vbaProject.bin`과 VBA 관계 정보
- `정리본` 시트의 버튼 도형 및 매크로 연결
- 다섯 개 버튼의 위치, 색상, 문구와 기능
  - 집행잔액 있는 항목
  - 원인행위·지출 불일치
  - 전체 보기
  - 자료 리셋
  - 저장 후 종료
- 셀 스타일, 열 너비, 행 높이, 필터, 틀 고정, 인쇄 설정

## 데이터 반영

- `불러온원본`: 업로드한 102-2 원본 전체 행을 교체한다.
- `추경검토`: 기존 확정본과 동일한 상단 요약 및 상세 행을 생성하고 웹에서 입력한 부서별 집행예정액과 추경안을 반영한다.
- `정리본`: 예산현액, 원인행위, 지출, 집행잔액, 불일치, 집행률과 추경안을 반영한다.
- `단위사업별집계`: 정책사업·단위사업·세부사업별 집계 및 마지막 합계를 반영한다.
- 데이터 행 수에 맞춰 자동필터 범위, 합계 수식 및 인쇄 영역을 조정한다.

## 생성 구조

일반 버튼은 기존 ExcelJS 생성기를 사용한다. 매크로 버튼은 배포 파일에 포함된 기준 `.xlsm` 템플릿을 바이너리로 읽고 ZIP 패키지의 데이터 시트 XML을 갱신한 뒤, 변경하지 않은 VBA·드로잉·관계 파일을 그대로 묶어 다운로드한다. 두 방식 모두 서버나 사용자 파일 저장소에 업로드 자료를 전송하지 않는다.

## 오류 처리

- 매크로 템플릿을 불러오지 못해도 일반 `.xlsx` 다운로드는 계속 사용할 수 있다.
- 두 다운로드 중 실패한 형식에 맞는 재시도 안내를 표시한다.
- 102-2 형식 검증 실패 시 현재 업로드 오류 안내를 유지한다.
- 생성된 패키지에서 VBA 또는 버튼 관계가 누락되면 파일을 다운로드하지 않는다.

## 검증 기준

- 출력 파일 콘텐츠 형식이 매크로 사용 통합 문서인지 검사한다.
- `vbaProject.bin`, 두 드로잉, 정리본 드로잉 관계가 출력 패키지에 존재하는지 자동 검사한다.
- 실제 102-2 자료 기준 네 데이터 시트의 행 수, 핵심 합계와 수식을 기존 검증값과 대조한다.
- LibreOffice 렌더링으로 표와 버튼의 위치를 육안 확인한다.
- Windows Excel에서 다섯 버튼을 각각 눌러 필터, 전체 보기, 리셋 및 저장 후 종료 동작을 최종 확인한다.
- 일반 `.xlsx`와 버튼 포함 `.xlsm`의 파일명, MIME, 데이터 합계를 각각 자동 검사한다.
- 기존 추경 기능 테스트와 운영 빌드를 통과한 뒤 Vercel 미리보기에 배포한다.

## 배포 절차

미리보기에서 `.xlsm` 다운로드와 버튼 표시를 확인받은 후에만 기존 `school-budget-portal` 운영 배포로 승격한다.

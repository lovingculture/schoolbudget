# 본예산 편성 기초자료 Excel 분석·미리보기 설계

## 목표

사용자가 K-에듀파인에서 내려받은 세입·세출예산서 Excel 파일을 웹에 올리면, 사이트가 내용을 분석해 제공된 `★학교 본예산편성 기초자료_올해세입작성용.xlsm`의 결과 구조에 맞춰 정리하고 실제 Excel과 유사한 표로 미리 보여준다. 분석이 끝나면 결과 Excel과 작업용 매크로 양식을 팝업에서 내려받을 수 있게 한다.

## 확정된 사용자 흐름

1. 페이지 상단에서 `세입세출예산서 엑셀로 다운 받기` 안내를 확인한다.
2. `.xls` 또는 `.xlsx` 형식의 세입·세출예산서 파일을 선택한다.
3. 사이트가 브라우저 안에서 파일을 분석한다. 원본 파일은 외부로 전송하지 않는다.
4. 분석 결과를 `세입`, `세출(원안)`, `세출(조정안)`, `업무추진비` 시트 탭으로 확인한다.
5. `엑셀 자료 내려받기` 버튼을 누르면 팝업이 열리고 `분석 결과 Excel` 또는 `작업용 매크로 양식`을 선택해 내려받는다.

## 입력과 분석

- 지원 입력은 `.xls`, `.xlsx`이다. 기존 CSV 분석은 호환성을 위해 계속 허용하되 기본 안내와 선택 화면에서는 Excel을 우선한다.
- 업로드 파일에서 세입·세출 명세서 영역을 제목과 열 이름으로 탐지한다.
- 학교별 행 수, 빈 행, 병합 셀, 숫자/문자 금액 표기를 정규화한다.
- 기존 `FoundationBudgetDocument`를 공통 결과 모델로 사용해 CSV와 Excel 분석 결과가 동일한 검증·미리보기·내려받기 흐름을 거치게 한다.
- 합계가 맞지 않거나 필수 영역을 찾지 못하면 내려받기를 막고 이해하기 쉬운 오류를 표시한다.

## Excel형 미리보기

- 일반 반응형 표처럼 열을 압축하지 않는다. Excel 출력 열 너비를 기준으로 최소 너비를 지정하고 표 영역 내부에 가로·세로 스크롤을 둔다.
- 제목, 요약 합계, 고정 머리글, 데이터 행, 금액 표시, 테두리, 배경색을 실제 생성 파일과 같은 계열로 표현한다.
- 금액은 오른쪽 정렬과 천 단위 구분을 적용한다.
- 긴 산출내역·산출식은 셀 안에서 정돈된 줄바꿈을 사용하고 나머지 열은 한 줄을 우선한다.
- 시트 탭은 `세입`, `세출(원안)`, `세출(조정안)`, `업무추진비` 순서이며 키보드로도 전환할 수 있다.
- 미리보기는 사용자가 업로드한 실제 분석 결과를 표시하며 정적인 예시 이미지로 대체하지 않는다.

## 내려받기 팝업

- 결과 검증이 끝나면 `엑셀 자료 내려받기` 버튼을 활성화한다.
- 팝업 항목은 `분석 결과 Excel`과 `작업용 매크로 양식` 두 가지다.
- `분석 결과 Excel`은 매크로 없는 `.xlsx`로 생성한다.
- `작업용 매크로 양식`은 사용자가 제공한 원본 `.xlsm` 파일을 내용 변경 없이 첨부 다운로드로 제공한다.
- 팝업은 초점 이동, Escape 닫기, 배경 클릭 닫기, 명확한 닫기 버튼을 지원한다.

## 문구

- 안내 제목: `세입세출예산서 엑셀로 다운 받기`
- 안내 설명: `예산서현황에서 세입예산명세서와 세출예산명세서를 각각 클릭한 뒤 Excel(.xls 또는 .xlsx)로 저장합니다.`
- 업로드 설명: `세입예산명세서와 세출예산명세서가 포함된 Excel 파일을 올려주세요.`
- CSV만을 전제로 한 기존 홈 및 이용안내 설명도 Excel 중심으로 고친다.

## 반응형·접근성

- 작은 화면에서는 표 자체를 축소하지 않고 미리보기 카드 안에서 스크롤한다.
- 주요 본문은 16px 이상, 표 머리글과 조작 라벨은 14px 이상을 유지한다.
- 탭, 파일 선택, 분석, 팝업 다운로드는 키보드와 스크린리더에서 식별 가능해야 한다.

## 검증 기준

- Excel 입력을 분석해 네 시트의 데이터와 합계를 만든다.
- 미리보기에서 열이 겹치거나 글자가 세로로 한 글자씩 깨지지 않는다.
- 결과 `.xlsx`가 정상적으로 열리고 네 시트와 수식·서식을 포함한다.
- 제공된 `.xlsm`이 브라우저 미리보기로 열리지 않고 첨부 파일로 내려받아진다.
- 기존 CSV 입력과 임시저장 결과가 깨지지 않는다.

# 본예산 세출 요구서 XLS·XLSX 양식 다운로드 설계

예산지침 화면에 `부서별 본예산 세출 요구자료 양식` 카드를 추가하고 `구형 Excel 양식(XLS)`과 `일반 Excel 양식(XLSX)` 두 다운로드 버튼을 제공한다.

두 파일은 `세출예산서식` 시트와 동일한 11개 열을 같은 순서로 제공한다. 기존 `budget.xls`의 VBA 사용자 정의 함수와 개인 메타정보는 포함하지 않는다. 요구금액과 증감은 업로드 후 포털에서 산출식과 전년요구금액을 이용해 계산한다.

파일은 사용자가 버튼을 누를 때 브라우저 내부에서 생성한다. 두 형식 모두 본예산 세출 파서로 다시 업로드할 수 있어야 하며, 빈 양식은 `입력 자료 없음`으로 정상 인식해야 한다.

자동검사는 두 파일의 시트명·열 순서·형식과 본예산 파서 호환성을 확인한다.

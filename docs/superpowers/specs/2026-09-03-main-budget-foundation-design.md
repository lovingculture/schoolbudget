# 본예산 편성 기초자료 만들기 설계

## 목표

K-에듀파인에서 내려받은 세입·세출 통합 CSV 한 파일을 브라우저에서 분석하고, 사용자가 내용을 확인한 뒤 본예산 편성 기초자료 Excel 파일(.xlsx)을 내려받을 수 있게 한다.

첫 버전은 `000 (2).csv`와 `학교본예산편성_자동화_CSV지원.xlsm`을 기준으로 정확히 동작하게 만든다. 다만 특정 행 번호에 의존하지 않아, 이후 다른 학교·학교급 샘플을 추가해 인식 범위를 확장할 수 있어야 한다.

## 사용자 흐름

1. 홈페이지에서 `본예산 편성 기초자료 만들기`를 선택한다.
2. K-에듀파인 세입·세출 통합 CSV 한 파일을 선택한다.
3. 브라우저가 문자 인코딩과 세입·세출 구간을 자동으로 판별한다.
4. 화면에서 회계연도, 예산구분, 세입·세출 합계, 추출 건수와 검증 결과를 확인한다.
5. 문제가 없으면 미리보기에서 세입, 세출 원안, 업무추진비 편성 현황을 확인한다.
6. `Excel 내려받기`를 눌러 매크로 없는 `.xlsx` 결과물을 저장한다.
7. 페이지를 닫았다 다시 열어도 마지막 변환 결과를 현재 브라우저에서 복원할 수 있다.

## 입력 규칙

- 첫 버전 입력은 CSV 한 파일이다.
- UTF-8과 EUC-KR/CP949를 자동 판별한다.
- 파일 내용에서 `세입예산명세서`와 `세출예산명세서` 제목을 찾아 구간을 구분한다.
- `세입합계`와 `세출합계` 행을 각 구간의 종료 및 원본 합계 검증값으로 사용한다.
- 페이지마다 반복되는 제목, 예산구분, 단위, 표 머리글은 데이터에서 제외한다.
- 계층형 행의 빈 장·관·항·목·정책사업·단위사업·세부사업 값은 직전 유효값으로 복원한다.
- 금액의 쉼표, 따옴표와 빈 값을 정규화하되 원본 문구와 산출기초는 보존한다.
- 구조를 확정할 수 없는 행은 임의로 버리지 않고 확인 필요 항목으로 남긴다.

## 분석 및 검증

- 추출한 세입 상세 합계와 원본 `세입합계`를 대조한다.
- 추출한 세출 상세 합계와 원본 `세출합계`를 대조한다.
- 세입합계와 세출합계를 서로 대조한다.
- 회계연도, 예산구분, 단위가 확인되지 않으면 오류로 표시한다.
- 필수 머리글이나 합계 행이 없으면 Excel 생성 버튼을 비활성화한다.
- 일부 행만 해석하지 못한 경우 행 번호와 원문을 경고 목록에 표시한다.
- 현재 샘플과 구조가 다른 파일은 잘못된 결과를 만들지 않고 `지원 형식 확인 필요`로 종료한다.

## 결과 화면

결과 화면은 다음 정보를 한눈에 보여준다.

- 파일명, 회계연도, 예산구분
- 세입합계, 세출합계, 차액
- 세입 상세 건수, 세출 상세 건수
- 업무추진비 요구액과 3% 편성한도
- 일치·불일치·확인 필요 상태
- 해석하지 못한 행과 원본 위치

표가 길어질 수 있으므로 화면에서는 검색, 열별 필터, 전체 선택·해제와 가로 스크롤을 제공한다. 모바일에서는 요약 카드를 먼저 표시하고 상세 표는 가로 스크롤로 유지한다.

## Excel 출력

결과물은 매크로 없는 `.xlsx`로 생성하며 첨부 자동화 문서의 구성과 서식을 기준으로 한다.

- `안내`: 생성일, 원본 파일명, 사용 방법과 검증 결과
- `세입`: 세입 분류, 산출내역, 산출식, 예산액, 예산성격과 합계
- `세출(원안)`: 부서명, 세부사업명, 세부항목명, 원가통계비목명, 산출내역, 산출식, 요구금액, 담당자, 전년 값과 증감
- `세출(조정안)`: 원안과 조정금액을 비교할 수 있는 편집용 표
- `업무추진비`: 업무추진비 항목과 요구금액, 조정금액, 증감, 전년도 예산 및 3% 한도
- `참고자료(통합교부비목록)`
- `참고자료(개별운영비목록)`

합계, 차액, 증감과 3% 한도는 Excel 수식으로 생성한다. 사용자가 내려받은 뒤 금액을 수정해도 계산 결과가 갱신되어야 한다. 출력 파일에는 원본 매크로를 포함하지 않는다.

## 데이터 분류

첫 버전의 예산성격과 업무추진비 분류는 첨부 자동화 문서의 표와 계산식을 기준으로 구현한다.

- 공통경상운영비
- 통합교부비
- 일반 재원(사용료·수수료 등)
- 수익자부담경비
- 업무추진비 원가통계비목

분류 근거가 명확하지 않은 항목은 자동 확정하지 않고 사용자가 결과 화면에서 확인·수정할 수 있게 한다. 이후 다른 학교 샘플로 분류 규칙을 보완한다.

## 임시저장과 보안

- 원본 CSV 파일 자체는 서버로 전송하거나 저장하지 않는다.
- 파싱과 Excel 생성은 브라우저 안에서 수행한다.
- 복원에 필요한 정규화 데이터와 사용자 수정값만 브라우저 저장소에 보관한다.
- 저장 형식에 버전을 두어 구조가 바뀌면 오래된 임시저장 데이터를 안전하게 폐기한다.
- `새 파일 분석`과 `임시저장 삭제` 기능을 제공한다.

## 구성 요소

- `MainBudgetFoundationPage`: 전체 작업 흐름과 상태 관리
- `FoundationCsvUpload`: 파일 선택과 형식 안내
- `parseFoundationCsv`: 인코딩 판별, 구간 분리, 계층 복원
- `validateFoundationBudget`: 합계와 필수 구조 검증
- `FoundationSummary`: 주요 합계와 상태 카드
- `FoundationDataGrid`: 검색·필터·수정 가능한 세입·세출 표
- `buildFoundationWorkbook`: 수식과 서식을 포함한 `.xlsx` 생성
- `foundationStorage`: 브라우저 임시저장과 버전 관리

기존 본예산 업무추진비 3% 확인 기능과 파서 유틸리티를 공유할 수 있지만, 결과 자료 구조와 저장 키는 별도로 둔다.

## 오류 처리

- 지원하지 않는 확장자: CSV 선택 안내
- 한글 인코딩 판별 실패: 다른 인코딩으로 다시 저장하는 방법 안내
- 세입 또는 세출 구간 누락: 누락된 구간 이름 표시
- 합계 불일치: 계산 차액과 관련 구간 표시
- Excel 생성 실패: 입력 상태는 유지하고 재시도 제공
- 브라우저 저장공간 부족: 작업은 계속 허용하되 임시저장 실패를 안내

## 테스트 및 완료 기준

- 현재 제공된 CSV에서 세입·세출 구간과 합계를 정확히 추출한다.
- 반복 머리글과 빈 행을 데이터로 포함하지 않는다.
- 행 수가 바뀐 변형 테스트에서도 제목과 합계 기준으로 구간을 찾는다.
- EUC-KR과 UTF-8 CSV 테스트를 통과한다.
- 합계 불일치와 필수 구간 누락 시 Excel 생성을 차단한다.
- 생성한 `.xlsx`를 다시 열어 시트명, 주요 값, 수식과 합계를 검증한다.
- 데스크톱과 모바일 화면에서 업로드, 미리보기, 내려받기 흐름을 확인한다.
- 기존 예산 업무 화면의 테스트와 빌드가 모두 통과한다.

## 후속 확장

첫 버전은 제공된 `000 (2).csv`에서 CP949/EUC-KR 인코딩, 세입·세출 각 1,010,749천원, 상세 행 합계와 7개 결과 시트 생성을 검증했다. 계층 행의 금액 열이 행 수준에 따라 앞당겨지는 K-에듀파인 CSV 구조도 행 번호에 의존하지 않고 인식한다.

다른 학교·학교급 CSV가 제공되면 익명화된 회귀 샘플로 추가한다. 열 이름 변형과 추가 분류 규칙은 기존 샘플을 깨뜨리지 않는 범위에서 확장하며, 첫 버전에서 자동 분류되지 않은 세입 항목은 `확인`으로 표시한다.

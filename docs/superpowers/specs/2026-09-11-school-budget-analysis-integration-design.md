# 학교별 예산 분석 통합 설계

## 목적

`lovingculture/sen-budget`의 서울 학교회계 결산 분석 기능과 2025회계연도 1,653개 학교·유치원 자료를 `schoolbudget`에 통합한다. 기존 예산 업무, 결산 설명서, 자료실, 영상, 웹툰 기능은 그대로 유지한다.

## 사용자 경험

- 상단 메뉴에 `학교별 예산 분석` 탭을 추가한다.
- 사용자는 1,653개 학교 전체를 학교명으로 검색하고 선택할 수 있다.
- 선택한 학교의 결산 총괄, 학교 기본 현황, 세입 구조, 세출 구조, 주요 지출과 세부 내역을 확인한다.
- PC에서는 넓은 표와 그래프를 활용하고, 모바일에서는 같은 정보를 세로 카드와 필요한 가로 스크롤 표로 배치한다. 화면 크기에 따라 정보가 생략되지는 않는다.
- 자료의 회계연도, 기준년월, 학교 코드와 공개 원문 출처를 표시한다.

## 통합 방식

현재 `schoolbudget`의 Vite·React 단일 페이지 구조를 유지한다. `sen-budget`의 Next.js 서버 화면을 그대로 포함하지 않고, 재사용 가능한 계산·검증 로직과 분석 화면을 현재 구조에 맞는 독립 기능 모듈로 옮긴다. 이 방식은 두 프레임워크를 함께 운영할 때 생기는 배포 복잡성을 피하고 기존 기능에 미치는 영향을 줄인다.

새 기능은 `src/features/schoolAnalysis` 아래에 둔다. 상단 메뉴와 전체 화면 전환에는 기존 포털의 `view` 흐름을 사용한다. 분석 화면의 스타일은 현재 사이트의 색상, 글꼴, 카드 모양과 반응형 규칙을 따른다.

## 데이터 구조와 성능

- 학교 검색용 목록에는 학교명, 학교 코드, 회계연도, 기준년월과 파일 경로만 둔다.
- 1,653개 학교의 결산자료는 학교별 JSON 파일로 분리해 공개 정적 자산으로 제공한다.
- 첫 화면에서는 검색용 목록만 받고, 학교를 선택한 뒤 해당 학교 JSON 한 개만 동적으로 불러온다.
- 같은 학교를 다시 선택할 때는 브라우저 메모리 캐시를 사용한다.
- 검색 결과는 일치하는 일부 항목만 화면에 그려 긴 목록으로 인한 렌더링 지연을 막는다.
- 학교 기본정보 자료도 선택된 학교에 필요한 항목만 빠르게 찾을 수 있도록 학교 코드 기준으로 분할하거나 인덱싱한다.
- 원본 1,653개 자료를 하나의 JavaScript 묶음에 포함하지 않는다.

## 데이터 출처와 변환

`sen-budget` 저장소의 검증된 2025 결산 fixture 1,653건, manifest, 학교 기본정보와 출처 정보를 기준으로 가져온다. 데이터 값은 임의로 수정하지 않는다. 빌드 전 변환 스크립트가 다음을 검증한다.

- manifest의 학교 수가 정확히 1,653개인지
- 각 학교 파일이 존재하며 학교 코드·회계연도·기준년월이 목록과 일치하는지
- 결산 합계와 세입·세출 계층에 필요한 필드가 유효한지
- 학교 기본정보가 다른 학교에 잘못 연결되지 않았는지

수집기, 데이터베이스 서버, 관리자용 크롤링 도구는 현재 공개 사이트에 포함하지 않는다. 이번 통합은 저장소에 이미 있는 검증된 공개 결산자료를 읽기 전용으로 제공하는 범위다.

## 분석 화면 구성

1. 학교 검색과 선택
2. 학교명, 학교 코드, 회계연도, 기준년월, 출처
3. 결산 핵심 수치 카드
4. 학교 기본 현황과 규모 참고정보
5. 세입 구조 분석
6. 세출 구조와 주요 지출 분석
7. 계층 탐색, 상위 항목, 상세 표

그래프를 사용할 수 없는 환경에서도 동일 내용을 표와 숫자로 확인할 수 있게 한다. 금액은 원 단위로 보존하고 화면에서만 읽기 쉬운 단위로 표시한다.

## 오류 처리

- 학교 목록을 읽지 못하면 다시 시도할 수 있는 안내를 표시한다.
- 선택한 학교 파일이 없거나 손상되면 다른 학교 검색 기능은 유지하고 해당 학교 자료 오류만 알린다.
- 데이터 검증에 실패한 파일은 잘못된 수치로 표시하지 않는다.
- 로딩 중에는 학교 선택 상태와 화면 구조를 유지해 화면이 튀지 않게 한다.

## 기존 기능 보호

- 기존 메뉴명과 화면 전환 동작은 변경하지 않는다.
- 기존 `결산 설명서 만들기`와 새 `학교별 예산 분석`을 별도 화면으로 유지한다.
- 기존 파일 업로드, 다운로드, 예산 분석, 자료실, 영상, 웹툰 흐름의 회귀 검사를 그대로 실행한다.
- 현재 공개 사이트는 별도 브랜치 검증이 끝날 때까지 변경하지 않는다.

## 검증 기준

- 기준 브랜치의 기존 자동 검사 516개가 계속 통과한다.
- 학교 목록이 1,653개이며 대표 학교를 이름으로 검색할 수 있다.
- 서로 다른 학교의 자료를 연속 선택해도 수치와 출처가 섞이지 않는다.
- 결산 계산 결과가 `sen-budget` 기준 결과와 일치한다.
- PC와 모바일 화면에서 검색, 선택, 분석표와 그래프 탐색이 가능하다.
- 새 기능의 로딩·오류·빈 결과 상태를 검사한다.
- 최종 빌드가 성공하고 브라우저에서 주요 사용 흐름과 콘솔 오류를 확인한다.

## 브랜치와 완료 조건

작업은 `codex/integrate-school-analysis` 브랜치의 분리된 작업 공간에서 수행한다. 구현과 검증이 끝나면 브랜치에 커밋하고 원격 저장소에 푸시한다. 사용자의 별도 지시 없이 `main`에 병합하거나 현재 공개 사이트를 교체하지 않는다.

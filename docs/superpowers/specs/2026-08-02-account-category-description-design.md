# 원가통계비목 설명 연동 기능 설계

## 목표

성립전예산의 각 예산항목에서 원가통계비목을 선택하면 해당 비목의 설명을 바로 옆에서 확인할 수 있게 한다. 사용자가 비목의 적용 범위를 이해하면서 입력할 수 있도록 선택 변경과 설명 표시를 실시간으로 연동한다.

## 확정 범위

- 현재 원가통계비목 20개와 표시 순서를 유지한다.
- `일반업무추진비`는 추가하지 않는다.
- 기본 선택값 `일반수용비`를 유지한다.
- 예산항목마다 선택된 비목에 대응하는 설명을 독립적으로 표시한다.
- 단위사업·세부사업, 산출내역, 금액 계산 등 기존 기능은 변경하지 않는다.

## 화면 배치와 동작

- 원가통계비목 선택창 오른쪽에 연한 배경과 테두리를 가진 `비목 설명` 상자를 표시한다.
- 설명 상자는 긴 문장을 줄바꿈하여 생략 없이 모두 표시한다.
- 원가통계비목을 변경하면 같은 예산항목의 설명만 즉시 변경한다.
- 예산항목을 추가하면 새 항목의 기본 비목인 `일반수용비` 설명을 표시한다.
- 화면 폭이 좁으면 설명 상자를 원가통계비목 선택창 아래로 배치한다.
- 설명은 안내 정보이며 사용자가 직접 편집하는 입력칸으로 만들지 않는다.

## 비목별 설명 데이터

1. `공무직인건비`: 공무원이 아닌 기간의 정함이 없는 근로계약을 체결한 근로자 인건비(퇴직급여, 처우개선비, 각종수당 등 포함)
2. `기간제교원인건비`: 공무원이 아닌 민간인 신분의 기간제 계약 교원 인건비(퇴직급여 포함)(정규 기간제교원, 대체 기간제교원, 시간강사 등)
3. `기간제근로자인건비`: 공무원이 아닌 민간인 신분의 기간제 근로자 인건비(퇴직급여 포함)(기간제 계약직, 일용직 등)
4. `기타수당`: 각종 법률에 따라 교직원에게 지급하는 수당 및 기타 실비변상적 경비(수석교사 연구활동비, 순회교사 및 복식수업수당 등)
5. `일반수용비`: 학교 운영에 소요되는 일반적인 경비(사무용품 구입비, 감사패·상패 등의 제작비, 인쇄비, 소모성 물품구입비, 비품 수선비, 각종 사용료(소프트웨어사용료 포함) 및 수수료, 시설물 소규모 수선비, 시설장비유지비, 청소용역비, 시설장비위탁 용역비, 임차료, 각종봉사료 등)
6. `운영수당`: 학교 운영 과정에서 외부강사나 교직원 등에게 지급하는 각종 수당 및 기타 실비지급 경비(강사수당, 외부강사 교통비 및 숙박비 등)
7. `급식용식재료비`: 급식에 소요되는 식재료비
8. `우유급식비`: 우유급식에 소요되는 우유구입비
9. `여비`: 공무원여비규정에 의한 여비, 이전비 및 민간인 여비
10. `맞춤형복지비`: 교직원(교육공무직원) 맞춤형 복지비
11. `교직원복지비`: 교직원 맞춤형복지비를 제외한 교직원복지비(피복비, 특근매식비, 직무관련연수비(교원자비부담연수비), 일반직공무원 자기개발비, 교직원보건검사비, 교직원 동호회지원, 소속 교직원(교장 포함) 생일기념 경비 등)
12. `교육운영비`: 학생 교과활동 지원을 위해 소요되는 각종 경비[교구, 기자재구입(자산성 물품은 비품구입비 목에 편성) 및 유지 보수비, 구독형 교육용 소프트웨어 구입비, 전자책 구독료, 교육용 재료비, 교육활동 숙박비·식비·차량임차료·교통비, 학생여비, 학교행사비, 학생대회출전비, 도서관운영비, 학급교육활동경비, 교육활동 입장료 및 체험비, 학생간식비, 동아리교육활동 등]
13. `학습준비물`: 학습준비물 구입비
14. `학생복지비`: 학생 복지에 소요되는 경비(장학금, 학생자치활동, 학교안전공제회비, 학생보건검사비, 졸업앨범비, 교복구입비, 학생 정서행동 검사 및 치료비 등)
15. `기간제교원법정부담금`: 기간제교원(정규·대체 기간제교원, 시간강사 등)에 대하여 기관(학교)이 부담해야 하는 법정부담금(국민연금, 건강보험, 고용보험, 산재보험 등)
16. `기간제근로자법정부담금`: 기간제근로자(기간제 계약직, 일용직 등) 및 방과후강사에게 기관(학교)이 부담해야 하는 법정부담금(국민연금, 건강보험, 고용보험, 산재보험 등)
17. `공무직법정부담금`: 공무직(호봉제·월급제 공무직 등)에 대하여 기관(학교)이 부담해야 하는 법정부담금(국민연금, 건강보험, 고용보험, 산재보험 등)
18. `목적사업업무추진비`: 지방자치단체 및 교육청, 공공기관에서 지원한 사업비로 특정목적을 수행하기 위하여 추진하는 사업의 업무추진비
19. `비품구입비`: 자산의 변동을 가져오는 물품 구입비
20. `도서구입비`: 도서대장에 등재되는 도서구입비

## 데이터 구조

- 기존 `DEFAULT_ACCOUNT_CATEGORIES`의 두 번째 값을 위의 전체 설명으로 교체한다.
- 선택된 비목명으로 설명을 찾는 순수 조회 함수를 도메인 모듈에 둔다.
- 비목을 찾지 못하면 빈 문자열을 반환하여 화면 오류가 발생하지 않게 한다.
- 화면은 현재 예산항목의 `category` 값을 조회 함수에 전달하고 반환된 설명을 표시한다.

## 테스트 및 검증

- 원가통계비목이 기존과 동일하게 20개인지 검증한다.
- `일반업무추진비`가 선택지에 없는지 검증한다.
- 기본값 `일반수용비`의 전체 설명이 표시되는지 검증한다.
- 선택값을 `공무직인건비` 등 다른 비목으로 변경하면 해당 설명으로 즉시 바뀌는지 검증한다.
- 두 개 이상의 예산항목에서 각 설명이 독립적으로 표시되는지 검증한다.
- 전체 테스트와 TypeScript·Vite 빌드를 실행한다.

## 배포 원칙

- 수정과 검증 후 Vercel Preview로만 배포한다.
- 사용자가 Preview를 확인하고 별도로 승인하기 전에는 운영 배포, promote, 운영 도메인 연결을 실행하지 않는다.

## 완료 기준

- 20개 비목 선택지가 기존 순서대로 유지된다.
- 각 비목의 전체 설명이 정확하게 연결된다.
- 선택 변경 시 같은 예산항목의 설명이 즉시 변경된다.
- 긴 설명이 생략되지 않고 읽을 수 있다.
- 전체 테스트와 빌드가 통과한다.
- Vercel Preview에서 사용자 확인이 가능하다.

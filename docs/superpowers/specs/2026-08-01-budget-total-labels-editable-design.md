# 예산 총 규모 표 제목 편집 기능 설계

## 목적

예산안건설명서 총 규모 표의 두 예산 제목은 현재 웹 문구를 기본값으로 유지하면서 사용자가 직접 수정할 수 있게 한다.

## 데이터

- `BudgetAgendaDraft`에 `revisedBudgetLabel`과 `previousBudgetLabel` 문자열을 추가한다.
- 기본값은 각각 `경정예산액(B)`, `기정예산액(A)`이다.
- 에듀파인 원본 금액과 계산식에는 영향을 주지 않는다.

## 입력 화면

- `총 규모` 편집 구역에 `경정예산 제목`과 `기정예산 제목` 입력칸을 추가한다.
- 사용자는 두 문구를 자유롭게 수정할 수 있다.
- 원본값 되돌리기 대상은 금액에 한정하고, 제목 입력칸은 일반 텍스트 입력으로 제공한다.

## 출력 반영

- 웹 미리보기의 총 규모 표 머리글에 수정된 문구를 표시한다.
- PDF, Word, Excel 내보내기에도 같은 문구를 표시한다.
- 증감 제목과 금액·증감률 계산은 기존 동작을 유지한다.

## 검증

- 초안 생성 시 기본 제목 두 개가 설정되는지 테스트한다.
- 편집 화면에서 제목을 바꾸면 초안 값이 변경되는지 테스트한다.
- 미리보기와 PDF·Word·Excel 내보내기에 변경된 문구가 반영되는지 테스트한다.
- 예산안건설명서 관련 테스트와 전체 빌드를 실행한다.

## 배포 제한

- Vercel `school-budget-portal` 프로젝트에 Preview로만 배포한다.
- 운영 배포, 운영 별칭 변경, Preview의 운영 승격은 수행하지 않는다.

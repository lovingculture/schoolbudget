# 2026학년도 예산편성지침 검색·미리보기 설계

## 목표

기존 `예산지침` 화면의 예시 자료 4개를 제거하고, 사용자가 제공한 실제 PDF `◆2026학년도 학교회계 예산편성 기본지침(수정).pdf` 한 건만 제공한다. 사용자는 216쪽 전체 본문을 검색하고, 검색 결과에서 관련 문장과 페이지를 확인한 뒤 해당 페이지를 사이트 안에서 바로 미리 볼 수 있어야 한다.

## 확정 범위

- 실제 `2026학년도 학교회계 예산편성 기본지침` 1건만 목록에 표시한다.
- 제목 검색과 PDF 216쪽 전체의 본문 키워드 검색을 지원한다.
- 검색 결과에는 페이지 번호와 검색어 주변 문장을 표시한다.
- 결과를 선택하면 사이트 안의 PDF 미리보기가 해당 페이지로 열린다.
- 전체 지침 보기와 원본 PDF 내려받기를 제공한다.
- 연도 선택은 `2026학년도`와 `전체 연도`를 유지하며, 현재 두 선택 모두 동일한 실제 문서 한 건을 대상으로 한다.
- 관리자 업로드 화면, AI 의미 검색, 데이터베이스, 사용자별 저장 기능은 이번 범위에서 제외한다.

## 구조

### 정적 문서

제공받은 원본 PDF를 Vite의 `public/guidelines/` 아래에 보관한다. 브라우저는 같은 Vercel 배포 주소에서 PDF를 읽으므로 별도 저장소나 인증 설정이 필요 없다.

### 검색 색인

PDF에서 페이지별 텍스트를 추출해 정적 JSON 색인을 생성한다. 각 항목은 다음 정보만 가진다.

- 실제 PDF 페이지 번호
- 검색용 정규화 텍스트
- 결과에 표시할 원문 텍스트

브라우저에서 검색어의 앞뒤 공백을 정리하고 대소문자를 통일한 뒤 제목과 페이지별 본문을 검색한다. 같은 페이지에 여러 번 나타나더라도 결과는 페이지당 한 건으로 묶고, 검색어 주변 문장을 발췌한다. 빈 검색어에서는 결과 목록을 숨기고 지침 카드만 표시한다.

### 화면 구성

기존 `예산지침` 페이지의 제목과 검색 영역은 유지하되 예시 카드들을 실제 문서 카드 한 건으로 교체한다.

1. 검색창과 연도 선택
2. 실제 PDF 문서 카드
3. 검색 시 결과 수와 페이지별 결과 목록
4. 선택 결과의 PDF 미리보기 영역

문서 카드에는 `미리보기`와 `내려받기` 버튼을 둔다. 검색 결과를 클릭하면 미리보기 영역으로 자연스럽게 이동하고 PDF 주소의 `#page=페이지번호`를 사용해 해당 페이지를 연다. PDF 미리보기는 브라우저 기본 PDF 표시 기능을 이용하며, 새 탭에서 전체 화면으로 여는 버튼도 제공한다.

## 데이터 흐름

1. 사용자가 검색어를 입력한다.
2. 클라이언트가 문서 제목과 정적 페이지 색인을 검색한다.
3. 페이지 번호와 검색어 주변 문장을 결과로 표시한다.
4. 사용자가 결과를 누른다.
5. 선택한 페이지 번호를 상태에 저장하고 PDF 미리보기 주소를 갱신한다.
6. 사용자가 전체 화면 또는 내려받기를 선택하면 같은 원본 PDF를 새 탭으로 열거나 내려받는다.

## 예외 처리

- 검색 결과가 없으면 `검색 결과가 없습니다. 다른 단어로 검색해 보세요.`를 표시한다.
- PDF 미리보기를 지원하지 않는 브라우저를 위해 `새 탭에서 열기`와 `내려받기`를 항상 함께 제공한다.
- 한 글자 검색도 허용하되 결과가 많을 때는 첫 50개 페이지만 표시하고, 결과 수 안내에 이를 명시한다.
- PDF나 색인을 불러오지 못하면 검색 영역에 오류 안내를 표시하되 원본 내려받기 버튼은 유지한다.

## 접근성 및 반응형

- 검색 결과는 키보드로 선택할 수 있는 버튼으로 구현한다.
- 현재 선택된 페이지를 시각적으로 구분하고 보조기기용 설명을 제공한다.
- 데스크톱에서는 결과 목록과 미리보기를 읽기 편한 폭으로 배치한다.
- 작은 화면에서는 검색 결과 위, PDF 미리보기 아래의 세로 배치로 전환한다.

## 테스트

- 실제 색인에서 표지, 목차 및 본문 키워드가 올바른 페이지를 반환하는지 단위 테스트한다.
- 공백 검색, 결과 없음, 다중 결과, 50개 제한을 검증한다.
- 결과 클릭 시 PDF 주소에 올바른 `#page=` 값이 들어가는지 컴포넌트 테스트한다.
- 실제 PDF와 색인이 배포 산출물에 포함되는지 빌드로 확인한다.
- 데스크톱과 모바일 화면에서 검색, 결과 선택, PDF 열기와 내려받기를 브라우저로 확인한다.

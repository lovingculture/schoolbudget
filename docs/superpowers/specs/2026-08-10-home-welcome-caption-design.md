# 홈 캐릭터 환영 문구 디자인

## 목표

홈 화면 캐릭터 위에 표시되는 흰색 말풍선을 제거하고 `환영합니다`라는 간결한 환영 문구만 표시한다.

## 변경 범위

- 기존 사용자 이름 기반 문구를 `환영합니다`로 교체한다.
- 말풍선의 흰색 배경, 그림자, 둥근 테두리, 내부 여백을 제거한다.
- 문구는 캐릭터 오른쪽 위에 청록색 굵은 일반 텍스트로 표시한다.
- 캐릭터 이미지, 캐릭터 크기, 홈 섹션 배치와 모든 업무 이동 기능은 유지한다.
- 좁은 화면에서도 문구가 캐릭터를 과도하게 가리지 않도록 기존 반응형 위치를 점검한다.

## 검증

- 홈 화면에 `환영합니다`가 표시된다.
- 기존 사용자 이름 기반 안내 문구는 표시되지 않는다.
- 환영 문구에 말풍선 배경과 그림자가 적용되지 않는다.
- 기존 홈페이지 테스트와 전체 빌드가 통과한다.

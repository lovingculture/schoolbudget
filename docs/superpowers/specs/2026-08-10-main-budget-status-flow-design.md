# 본예산 업무 진행 흐름도 설계

## 목표

본예산 페이지를 처음 연 사용자가 전체 업무 순서와 현재 준비 상태를 한눈에 이해할 수 있도록, 제목 아래에 읽기 전용 5단계 업무 흐름도를 표시한다.

## 범위

- 본예산 페이지 제목과 기존 자료 구분 탭 사이에 흐름도를 배치한다.
- 흐름도는 진행 상태만 표시하며 초기 버전에서는 클릭·화면 이동 기능을 제공하지 않는다.
- 기존 세출자료 업로드·통합·검토, 세입자료 탭, 브라우저 저장 데이터와 다운로드 기능은 변경하지 않는다.
- 구현되지 않은 기능을 완료 상태나 계산 결과처럼 표시하지 않는다.

## 단계와 상태

흐름도는 다음 순서를 고정해서 보여준다.

```text
예산계획 수립 → 전년도 자료 불러오기(에듀파인) → 부서 요구서 확인 → 조정 인사이트(대시보드) → 예산 확정
```

각 단계의 초기 상태는 다음과 같다.

1. 예산계획 수립: `준비 중`
2. 전년도 자료 불러오기(에듀파인): `자료 대기`
3. 부서 요구서 확인
   - 업로드 전: `자료 대기`
   - 업로드 후: 성공적으로 처리된 파일 수와 인식된 부서 수를 `파일 n개 · 부서 n개`로 표시
4. 조정 인사이트(대시보드): `세입·세출자료 대기`
   - 이후 대시보드 구현 시 조정 후보, 업무추진비 3% 한도 검토, 원가통계비목 적정성 검토, 전년도 대비 누락 예산항목 검토를 같은 단계와 화면에서 함께 표시한다.
   - 업무추진비 3% 검토를 별도 업무 단계로 분리하지 않는다.
5. 예산 확정: `준비 중`

부서 요구서 상태는 기존 `files`와 `rows`를 읽어 계산하며 해당 배열을 수정하지 않는다. 파일 수는 성공 상태인 파일만 세고, 부서 수는 공백을 제외한 고유 부서명 수로 계산한다. 전년도 자료, 조정 인사이트, 세입자료와 3% 검토 데이터는 아직 연결되지 않았으므로 계산값을 만들지 않고 대기 상태만 표시한다.

## 조정 인사이트의 원가통계비목 검토 원칙

조정 인사이트 대시보드를 구현할 때 원가통계비목은 다음 두 단계로 검토한다.

1. 기본 검토
   - 원가통계비목 누락 여부
   - 학교회계 표준 원가통계비목 명칭 또는 코드에 존재하는지 여부
   - 공백·오탈자·비표준 명칭 때문에 자동 연결할 수 없는 항목
2. 내용 적정성 검토
   - 세부사업·세부항목·산출내역과 선택한 원가통계비목의 일치 가능성
   - 지침 또는 검증된 규칙에서 명확히 제한하는 조합
   - 판단이 불확실한 경우의 권장 후보와 확인 근거

대시보드에는 정상·오류·확인 필요 건수와 함께 부서, 사업, 현재 원가통계비목, 문제 내용, 판단 근거, 권장 후보, 담당자 확인 여부를 표시한다. 산출내역의 키워드만으로 확정할 수 없는 항목은 자동 변경하지 않고 `확인 필요`로 표시한다. 표준 목록이나 지침 근거가 없는 추천은 확정값처럼 표시하지 않는다.

## 조정 인사이트의 전년도 누락 예산항목 검토 원칙

전년도 예산서를 불러온 뒤 올해 부서 요구자료와 비교해 전년도에는 있었지만 올해 자료에서는 찾지 못한 항목을 `누락 의심` 후보로 표시한다.

연결 순서는 다음과 같다.

1. 정책사업·단위사업·세부사업·세부항목·원가통계비목 코드가 있으면 코드를 우선 비교한다.
2. 코드가 없으면 공백·기호·연도 표현을 정규화한 사업명과 항목명을 비교한다.
3. 정확히 일치하지 않지만 명칭이 유사한 경우에는 자동 연결하지 않고 `유사 항목 확인 필요`로 표시한다.
4. 올해 자료에서 대응 항목을 찾지 못하면 `누락 의심`으로 표시하되 신규·종료·통합·명칭변경 사업일 수 있음을 함께 안내한다.

대시보드에는 전년도 부서, 사업·세부항목, 원가통계비목, 전년도 예산액, 올해 대응 후보, 연결 신뢰도, 판단 근거, 담당자 확인 상태를 표시한다. 사용자가 `올해 미편성`, `종료사업`, `다른 항목으로 통합`, `확인 완료` 중 하나로 검토 결과를 기록할 수 있게 설계한다. 이름이 비슷하다는 이유만으로 누락이나 동일 사업을 확정하지 않는다.

## 화면 구성

- 각 단계는 번호, 단계명, 상태 문구를 포함한 카드로 표시한다.
- 단계 사이에는 업무 순서를 나타내는 화살표를 표시한다.
- PC 화면에서는 5단계를 한 줄로 배치한다.
- 좁은 화면에서는 카드를 한 열로 배치하고 화살표 방향을 세로 흐름에 맞게 표현한다.
- 기존 포털의 네이비·민트·스카이 색상과 본예산 화면의 글자 크기·테두리·간격을 따른다.
- 흐름도는 `aria-label`이 있는 별도 영역으로 제공해 보조기술에서도 업무 순서를 이해할 수 있게 한다.

## 컴포넌트 경계

- 새 `MainBudgetStatusFlow` 컴포넌트는 `rows`와 `files`를 읽기 전용 속성으로 받는다.
- 상태 계산은 별도 순수 함수로 분리해 화면 렌더링과 독립적으로 검증한다.
- `MainBudgetPage`는 제목 아래에서 컴포넌트를 렌더링하기만 하며 기존 탭 상태와 업로드 동작을 유지한다.

## 오류 및 빈 상태

- 자료가 없으면 오류로 표시하지 않고 `자료 대기`로 안내한다.
- 처리 실패·빈 파일은 성공 파일 수에 포함하지 않는다.
- 부서명이 없는 행은 부서 수에 포함하지 않는다.
- 이후 기능이 구현되기 전까지 전년도 자료·조정 인사이트·예산 확정은 고정 대기 또는 준비 상태를 유지한다.
- 세입자료가 없으면 업무추진비 3% 한도나 사용률을 임의로 계산하지 않는다.
- 표준 원가통계비목이나 명확한 판단 규칙이 없으면 오류로 단정하지 않고 `확인 필요`로 표시한다.
- 전년도와 올해 사업명이 다르면 자동으로 누락 확정하지 않고 `누락 의심` 또는 `유사 항목 확인 필요`로 표시한다.

## 검증 기준

- 본예산 페이지 제목 아래, 기존 탭 위에 5단계가 순서대로 표시된다.
- 전년도 자료와 부서 요구서 업로드 전에는 `자료 대기`가 표시된다.
- 성공 파일과 서로 다른 부서 자료가 있으면 실제 개수와 일치하는 상태가 표시된다.
- 실패·빈 파일과 빈 부서명은 집계에서 제외된다.
- `조정 인사이트(대시보드)` 카드에는 업무추진비 3% 검토가 향후 같은 대시보드에 포함됨을 안내하고, 별도 단계는 만들지 않는다.
- 같은 조정 인사이트 카드에는 원가통계비목 적정성 검토도 포함됨을 안내한다.
- 전년도 자료가 연결되면 전년도 대비 누락 의심 건수를 같은 카드에 표시하고, 자료가 없으면 `전년도 자료 대기`로 표시한다.
- 단계 카드는 클릭 가능한 요소가 아니다.
- 1440px에서는 가로 흐름, 390px에서는 페이지 가로 넘침 없는 세로 흐름으로 표시된다.
- 기존 본예산 집중 테스트와 전체 빌드가 통과한다.

## 초기 흐름도 구현의 제외 사항

아래 기능은 조정 인사이트 대시보드 단계에서 구현하며, 이번 읽기 전용 흐름도 구현에는 포함하지 않는다.

- 편성계획 입력 화면과 일정 관리
- 단계별 클릭 이동
- 전년도 에듀파인 자료 실제 업로드·분석
- 전년도·올해 사업 자동 확정 연결
- 조정 인사이트 대시보드와 조정 시나리오 생성
- 세입자료 입력 및 업무추진비 3% 실제 계산
- 예산 확정 처리
- 진행 상태의 서버 저장 또는 사용자 간 공유
- Production 배포

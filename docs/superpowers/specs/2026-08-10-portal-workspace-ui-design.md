# 포털 업무 화면 UI 통일 설계

## 목표

홈 화면에 적용된 네이비·민트·하늘색 중심의 디자인 언어를 학교예산 지침, 예산 업무, 자료실과 동영상 안내 화면에 통일 적용한다. 업로드·엑셀 분석·자동계산·문서 생성 동작은 바꾸지 않고, 사용자가 업무 단계와 현재 상태를 더 쉽게 읽을 수 있게 한다.

## 적용 범위

- 학교예산 지침
- 성립전예산
- 본예산
- 안건설명서
- 결산설명서
- 추경예산자료
- 자료실
- 동영상 안내

## 제외 범위

- 한글(HWPX)·Word·PDF·Excel 다운로드 파일의 서식
- A4 문서 미리보기와 인쇄용 스타일
- 엑셀 업로드·파싱·검증·자동계산 로직
- 브라우저 저장 데이터 구조
- Production 배포 및 운영 도메인 변경

## 공통 디자인 체계

### 색상과 형태

- 제목과 핵심 텍스트: 홈 화면과 같은 네이비
- 주요 동작: 민트·청록 그라데이션 또는 청록 단색
- 보조 정보: 하늘색·연민트 배경 카드
- 오류·주의: 기존 의미를 유지하는 주황·코랄 계열
- 기본 카드: 흰색 배경, 16~20px 둥근 모서리, 연한 하늘·회색 테두리, 넉넉한 내부 여백
- 페이지 배경: 홈 업무 카드 영역과 어울리는 밝은 청회색

### 타이포그래피와 조작 요소

- 페이지 제목은 네이비, 30px 이상, 한 줄 안내는 읽기 쉬운 회청색 15~16px
- 카드 제목은 19~22px, 보조 설명은 14~16px
- 입력창·선택창·버튼은 최소 44px 높이를 기준으로 하고, 입력값은 최소 15~16px로 표시
- 주요 버튼은 민트·청록 배경과 흰색 글자, 보조 버튼은 흰색 배경·연한 테두리로 구분
- 키보드 포커스는 홈과 동일한 노란색 계열 외곽선으로 명확히 표시

### 공통 상태 표현

- 성공·진행·대기·주의·오류를 동일한 배지 형태와 색상으로 표시한다.
- 파일 업로드 결과, 자동점검 결과, 검토 건수, 진행 단계에서 같은 배지 규칙을 사용한다.
- 상태 색상만으로 의미를 전달하지 않고 텍스트를 함께 표시한다.

## 화면별 적용 방식

### 학교예산 지침·자료실·동영상 안내

- 페이지 제목 영역을 홈의 섹션 제목과 같은 계층으로 바꾼다.
- PDF·파일·동영상 카드에 아이콘 영역, 유형 배지, 설명, 명확한 열기·다운로드 버튼을 적용한다.
- 검색·필터는 둥근 흰색 도구 막대 안에 배치한다.

### 성립전예산·본예산·추경예산자료

- 기본정보, 파일 업로드, 예산항목, 대시보드, 결과 표를 업무 카드로 구분한다.
- 상단 단계 표시와 탭을 청록 선택선·상태 배지로 통일한다.
- 기존 성립전예산의 가독성 확대 규칙은 유지하며 새 공통 체계와 충돌하지 않게 업무 화면 범위 안에서만 적용한다.
- 표의 고정 헤더, 필터, 합계, 경고 상태를 공통 테이블 스타일로 맞춘다.

### 안건설명서·결산설명서

- 업로드·편집·자동점검·다운로드 영역만 공통 업무 카드로 바꾼다.
- A4 미리보기와 출력 전용 요소는 별도 클래스로 유지하여 페이지 크기·여백·표·글꼴이 바뀌지 않게 한다.

## 구현 구조

- 공통 색상 변수와 카드·버튼·상태·도구 막대 규칙은 새 업무 화면 스타일 파일에 둔다.
- 각 기능의 비문서 화면 최상위 요소에 `portal-workspace` 클래스를 추가한다.
- 기존 기능별 CSS는 레이아웃·표·문서 출력 규칙을 유지하고, 공통 시각 규칙은 `portal-workspace` 하위 선택자로만 덮어쓴다.
- A4 미리보기 요소(`.prebudget-paper`, `.closing-a4-page`, `.budget-agenda-a4-page` 등)는 공통 업무 카드 규칙에서 명시적으로 제외한다.
- 기능별 컴포넌트와 파서·저장소·다운로드 코드는 변경하지 않는 것을 원칙으로 한다.

## 적용 순서

1. 공통 디자인 토큰·업무 카드·탭·버튼·상태 배지 기반을 만든다.
2. 학교예산 지침·자료실·동영상 안내를 적용한다.
3. 성립전예산·본예산·추경예산자료를 적용한다.
4. 안건설명서·결산설명서의 비문서 영역을 적용한다.
5. 기존 기능 회귀 테스트와 데스크톱·모바일 실제 화면 검증을 수행한다.

## 검증 기준

- 각 대상 화면에 홈과 같은 네이비·민트·하늘색 계열과 공통 카드·버튼·입력·상태 표현이 적용된다.
- 지침 검색, 파일 업로드, 엑셀 분석, 자동점검, 필터·정렬, 임시저장, 다운로드가 기존과 동일하게 동작한다.
- 성립전예산의 16px 입력 가독성 규칙이 유지된다.
- A4 미리보기와 인쇄용 문서의 크기·여백·표·글꼴에 변화가 없다.
- 1440px 및 390px 화면에서 가로 넘침, 잘린 입력창, 겹치는 버튼이 없다.
- 키보드 포커스와 상태 텍스트가 보이며, 콘솔 오류가 없다.
- Preview 환경에서만 사용자 확인을 진행하고 Production 배포는 하지 않는다.

# 예산 웹툰 페이지 설계

## 목적

학교예산 안내 만화 1화부터 6화까지를 사이트 안에서 회차별로 찾아보고, 각 회차의 긴 원본 이미지를 모바일과 PC에서 편하게 읽을 수 있게 한다. 첫 화면에서는 학교예산 질의응답 외부 서비스로 바로 이동할 수 있게 한다.

## 첫 화면 학교예산 질의응답

- 첫 화면의 `새로운 소식을 확인하세요` 영역에 `학교예산 질의응답` 카드를 추가한다.
- 설명은 `학교예산 업무와 관련해 궁금한 내용을 질문하고 답변을 확인해 보세요.`로 표시한다.
- `질문하러 가기` 링크를 선택하면 Google Notebook 질의응답 페이지를 새 창으로 연다.
- 연결 주소는 `https://notebook.google.com/notebook/db7666d9-8e19-4d43-8f3e-b8f1345e7d08/preview`를 사용한다.
- 기존 소식 카드의 색상과 형태를 유지하며, 모바일에서는 한 열 전체 너비로 표시한다.

## 메뉴와 이동 구조

- 상단 주요 메뉴에 `예산 웹툰`을 추가한다.
- 메뉴를 선택하면 웹툰 목록 페이지를 연다.
- 목록에서 회차 카드를 선택하면 해당 회차의 상세페이지를 연다.
- 상세페이지에는 `목록으로`, `이전 화`, `다음 화` 이동을 제공한다.
- 1화에서는 `이전 화`, 6화에서는 `다음 화`를 표시하지 않는다.
- 브라우저의 이전 화면 동작도 기존 앱의 화면 이동 방식과 충돌하지 않도록 현재 사이트의 뷰 상태 구조를 따른다.

## 콘텐츠

제공받은 PNG 원본 6개를 사이트의 공개 이미지 자료로 복사하고, 편집·확대 생성 없이 그대로 사용한다.

1. 1화 — 학교예산, 왜 중요할까?
2. 2화 — 학교예산, 어떻게 편성될까?
3. 3화 — 성립전예산, 언제 어떻게 편성할까?
4. 4화 — 성립전예산, 어떻게 편성하지?
5. 5화 — 추가경정예산(추경)이란?
6. 6화 — 추경예산, 언제 어떻게 편성할까?

웹툰 정보는 회차, 제목, 이미지 경로를 가진 하나의 목록으로 관리하여 목록과 상세페이지가 같은 데이터를 사용하게 한다.

## 목록 화면

- 기존 포털의 색상, 둥근 카드, 제목 영역을 유지한다.
- 1화부터 6화까지 순서대로 카드 형태로 표시한다.
- 각 카드에는 이미지 상단 일부를 활용한 썸네일, 회차, 제목, `읽어보기` 동작을 표시한다.
- PC에서는 여러 열, 모바일에서는 한 열로 배치한다.
- 카드 전체를 키보드와 터치로 선택할 수 있게 한다.

## 상세 화면

- 상단에 회차와 제목, `목록으로` 버튼을 배치한다.
- 원본 비율을 유지하며 이미지 너비를 화면에 맞춘다.
- PC에서는 읽기 영역의 최대 너비를 제한해 과도하게 커지지 않게 하고, 모바일에서는 좌우 여백을 줄여 글자가 최대한 크게 보이게 한다.
- 이미지 아래에 이전 화·목록으로·다음 화 버튼을 다시 제공해 긴 웹툰을 다 읽은 뒤 바로 이동할 수 있게 한다.
- 이미지에는 회차와 제목을 포함한 대체 설명을 제공한다.

## 예외 처리

- 존재하지 않는 회차가 선택되면 목록 화면으로 안전하게 돌아간다.
- 이미지가 표시되지 않을 때에도 회차와 제목은 남아 사용자가 어떤 콘텐츠인지 알 수 있게 한다.

## 검증

- 상단 메뉴에서 웹툰 목록으로 이동하는지 확인한다.
- 6개 회차 카드와 제목이 순서대로 표시되는지 확인한다.
- 각 카드를 선택하면 올바른 이미지의 상세페이지가 열리는지 확인한다.
- 1화와 6화의 이전·다음 버튼 경계, 중간 회차의 양방향 이동을 확인한다.
- 목록 복귀와 모바일 한 열 배치 규칙을 확인한다.
- 첫 화면의 학교예산 질의응답 카드가 정확한 주소를 새 창으로 여는지 확인한다.
- 전체 자동 점검과 게시용 화면 생성을 통과한 뒤 GitHub에 저장하고 공개 사이트에 배포한다.

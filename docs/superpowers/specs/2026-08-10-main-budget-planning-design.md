# 본예산 편성계획 세우기 설계

## 목표

본예산 업무를 시작하기 전에 학교가 편성 기준, 부서별 제출 일정, 검토 일정과 상정 일정을 한 화면에서 정리하고, 이후 세출 수합·세입 검토·조정안 확정 단계의 진행 상태를 확인할 수 있게 한다.

## 범위

- 본예산 화면에 첫 번째 탭 `편성계획 세우기`를 추가한다.
- 기존 `세출자료 통합·검토`, `세입자료·3% 검토` 탭과 모든 업로드·수합·검토 기능은 유지한다.
- 계획 탭은 브라우저 내부에 임시저장하며, 새로고침 후에도 복원한다.
- 초기 버전은 계획 작성과 진행 현황 확인에 집중한다. 자동 일정 산정, AI 조정 제안, 다운로드 문서 생성은 포함하지 않는다.

## 화면 구성

### 1. 상단: 편성 기본계획

- 회계연도: 사용자가 수정 가능한 숫자 입력값
- 편성 가능액: 원 단위 숫자 입력, 천 단위 콤마 표시
- 전체 우선순위: 자유 입력 텍스트
- 필수사업: 줄 단위로 입력하는 목록
- 감액 제외사업: 줄 단위로 입력하는 목록
- `임시저장` 버튼과 `초기화` 버튼을 제공한다. 초기화는 확인창을 표시한다.

### 2. 중단: 부서별 제출계획

행 단위로 다음을 입력한다.

- 부서명
- 담당자
- 제출기한
- 메모

부서를 추가하거나 삭제할 수 있다. 세출자료가 업로드되면 같은 부서명 행의 상태를 `제출 완료`로 표시하고, 자료가 없으면 `제출 대기`로 표시한다. 자동 연결이 불확실한 경우에는 상태를 임의로 확정하지 않고 `확인 필요`로 표시한다.

### 3. 하단: 전체 일정 및 업무 흐름

다음 날짜를 각각 입력한다.

- 부서 자료 제출 마감일
- 세출 검토·조정 시작일
- 세입자료 입력 마감일
- 학교운영위원회 상정일

화면에는 다음 고정 흐름도를 표시한다.

```text
편성계획 수립 → 세출자료 통합·검토 → 세입자료·3% 검토 → 조정안 확정 → 안건설명서 작성
```

각 단계는 실제 상태를 함께 보여준다.

- 편성계획: 필수 기본값 입력 여부
- 세출자료 통합·검토: 업로드된 파일 수, 인식된 부서 수, 오류·확인 필요 건수
- 세입자료·3% 검토: 초기 버전에서는 `자료 입력 대기` 상태
- 조정안 확정: 초기 버전에서는 `준비 중` 상태
- 안건설명서 작성: 기존 예산 안건설명서 기능으로 이동하는 버튼

## 데이터와 연결 방식

- 기존 `mainBudgetStorage`는 저장된 세출 행과 파일 목록을 보존한다.
- 새 계획 데이터는 같은 본예산 저장소의 확장 필드로 저장한다. 이전에 저장된 세출 데이터만 있어도 계획 데이터는 기본값으로 복원되어 하위 호환성을 유지한다.
- 계획 탭의 진행 현황은 저장된 세출 행·파일 목록을 읽기만 하며, 기존 자료를 수정하거나 삭제하지 않는다.
- 세입자료가 아직 구현 전이므로 세입 및 3% 단계는 실제 계산 결과를 흉내 내지 않고 `자료 입력 대기`로 명확히 표시한다.

## 검증 기준

- 본예산 화면에 `편성계획 세우기` 탭이 첫 번째로 표시된다.
- 계획 입력값과 부서별 제출계획을 임시저장한 뒤 새로고침해도 복원된다.
- 초기화는 확인창 승인 후에만 계획 데이터를 지운다.
- 세출 파일을 올렸을 때 진행 현황의 파일 수와 부서 수가 기존 수합 데이터와 일치한다.
- 계획 탭은 기존 세출 행·파일 목록을 수정하지 않는다.
- 세입 단계는 구현되지 않은 계산값을 표시하지 않는다.
- PC 우선 레이아웃을 유지하고, 좁은 화면에서는 카드와 표가 읽을 수 있는 방식으로 정리된다.

## 제외 사항

- Production 배포 및 운영 도메인 변경
- 세입자료 입력 및 업무추진비 3% 실제 계산 구현
- 자동 일정 추천 또는 외부 AI 분석
- 계획서·조정안의 Excel, HWPX, PDF 다운로드

# 예산 자료실 개편 및 관리자 업로드 설계

## 목표

기존 `학교예산 지침` 화면을 홈 화면과 동일한 시각 체계의 `예산 자료실`로 개편한다. 기존 지침 검색, PDF 미리보기, 페이지 이동, PDF 다운로드 및 본예산 요구자료 양식 다운로드는 유지한다. 지정된 관리자 한 명은 웹에서 자료를 등록·수정·삭제하고, 로그인한 일반 사용자는 공개 자료를 검색·열람·다운로드할 수 있게 한다.

## 화면 구성

- 상단 메뉴와 화면 제목의 `학교예산 지침` 또는 `예산지침` 표기를 `예산 자료실`로 통일한다.
- 홈 화면의 하늘색·민트색 배경, 남색 제목, 둥근 카드, 44px 이상 조작요소를 그대로 사용한다.
- 상단 히어로에 `BUDGET RESOURCE LIBRARY`, `예산 자료실`, 안내 문구와 서울시교육청 공식 캐릭터를 배치한다.
- 검색창, 자료 유형 필터, 학년도 필터를 한 줄 도구 영역에 배치한다.
- 자료는 `예산편성 지침`, `업무서식`, `참고자료`로 분류한다.
- 자료 카드는 제목, 설명, 학년도, 파일 형식, 등록일, 열기 또는 다운로드 동작을 표시한다.
- 관리자에게만 `자료 등록`, `수정`, `삭제` 동작을 표시한다.
- 모바일에서는 검색·필터·카드를 한 열로 배치하고 페이지 전체 가로 스크롤이 발생하지 않게 한다.

## 기존 기능 보존

- 2026학년도 학교회계 예산편성 기본지침 검색 및 본문 검색 결과를 유지한다.
- 검색 결과에서 정확한 PDF 페이지로 이동하는 기능을 유지한다.
- PDF 미리보기, 새 탭 열기, PDF 내려받기를 유지한다.
- 구형 XLS 양식과 일반 XLSX 양식 다운로드를 유지한다.
- 기존 `자료실` 화면의 공개 자료를 새 `예산 자료실` 목록으로 통합하고 중복 메뉴는 제거한다.

## 저장 구조

현재 프로젝트가 사용 중인 Supabase를 그대로 활용한다.

### 파일 저장소

- 공개 파일 전용 Storage bucket을 사용한다.
- 실제 파일은 중복을 피하도록 생성된 고유 경로에 저장하고, 화면에는 원본 파일명을 표시한다.
- 허용 형식은 초기 버전에서 PDF, XLS, XLSX, DOCX, HWP, HWPX로 제한한다.
- 파일 크기 제한은 30MB로 한다.

### 자료 목록

자료 메타데이터 테이블은 다음 항목을 가진다.

- 자료 ID
- 제목
- 설명
- 분류
- 학년도
- 원본 파일명
- 저장 경로
- MIME 형식
- 파일 크기
- 공개 여부
- 등록자 ID
- 등록일 및 수정일

### 관리자 권한

- 기존 로그인 사용자의 고유 ID를 기준으로 관리자 한 명을 지정한다.
- 일반 사용자는 공개 자료 조회만 가능하다.
- 관리자는 자료 메타데이터와 Storage 파일을 등록·수정·삭제할 수 있다.
- 화면에서 버튼을 숨기는 것뿐 아니라 Supabase 정책에서도 관리자만 쓰기 작업을 수행할 수 있게 제한한다.

## 업로드 흐름

1. 관리자가 `자료 등록`을 누른다.
2. 제목, 설명, 분류, 학년도, 공개 여부와 파일을 입력한다.
3. 브라우저에서 확장자, MIME 형식, 30MB 제한과 필수값을 검사한다.
4. Storage 업로드가 성공하면 자료 목록을 저장한다.
5. 목록 저장이 실패하면 방금 업로드한 파일을 정리하고 이해하기 쉬운 오류를 표시한다.
6. 등록 완료 후 목록을 새로 불러오고 성공 메시지를 표시한다.

## 수정 및 삭제

- 파일을 바꾸지 않고 제목·설명·분류·학년도만 수정할 수 있다.
- 새 파일로 교체할 때 새 파일 저장 성공 후 기존 파일을 제거한다.
- 삭제 전 확인창을 표시한다.
- 삭제는 메타데이터와 저장 파일 모두를 대상으로 하며, 일부만 실패하면 관리자에게 재시도 가능한 상태를 안내한다.

## 오류 및 보안

- 허용하지 않는 형식, 용량 초과, 네트워크 오류, 권한 부족을 서로 다른 한글 메시지로 표시한다.
- 파일명은 화면 표시용으로만 사용하고 저장 경로로 직접 사용하지 않는다.
- 일반 사용자가 브라우저 개발자 도구로 쓰기 요청을 보내도 Supabase 정책에서 차단한다.
- 개인정보 포함 자료를 올리지 않도록 등록 화면에 경고 문구를 표시한다.

## 단계별 구현

1. 메뉴명과 `예산 자료실` 통합 화면 및 캐릭터 디자인 적용
2. 기존 지침 검색·PDF·양식 다운로드를 새 카드 구조에 연결
3. Supabase 테이블·Storage·권한 정책용 마이그레이션 작성
4. 관리자 판별과 등록·수정·삭제 화면 구현
5. 실제 PDF/XLS/XLSX/HWPX 업로드, 일반 사용자 열람, 권한 거부 검증
6. 전체 회귀 테스트 및 Vercel Preview 배포

Supabase 스키마와 Storage 정책 적용은 공유 백엔드 상태를 변경하므로, 마이그레이션 파일과 적용 내용을 먼저 검토한 뒤 별도 승인을 받고 실행한다. Production 승격과 운영 도메인 변경은 하지 않는다.

## 완료 기준

- 홈 화면과 시각적으로 연결된 `예산 자료실`이 데스크톱과 모바일에서 정상 표시된다.
- 기존 지침 검색·PDF 페이지 이동·다운로드와 XLS/XLSX 양식 다운로드가 유지된다.
- 관리자 계정만 실제 파일을 등록·수정·삭제할 수 있다.
- 일반 사용자는 공개 자료를 검색·열람·다운로드할 수 있고 쓰기 요청은 거부된다.
- 실제 허용 파일과 잘못된 파일, 용량 초과, 권한 부족을 검증한다.
- Preview 환경에서 사용자 확인을 받은 뒤에만 다음 배포 단계를 결정한다.

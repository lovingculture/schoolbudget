# 성립전예산 원가통계비목 20개 목록 교체 설계

## 목표

성립전예산 예산항목의 `원가통계비목` 콤보박스에 표시되는 기존 11개 목록을 사용자가 제공한 표준 20개 목록으로 완전히 교체한다.

## 확정 목록과 순서

1. 공무직인건비
2. 기간제교원인건비
3. 기간제근로자인건비
4. 기타수당
5. 일반수용비
6. 운영수당
7. 급식용식재료비
8. 우유급식비
9. 여비
10. 맞춤형복지비
11. 교직원복지비
12. 교육운영비
13. 학습준비물
14. 학생복지비
15. 기간제교원법정부담금
16. 기간제근로자법정부담금
17. 공무직법정부담금
18. 목적사업업무추진비
19. 비품구입비
20. 도서구입비

표시 문구와 순서는 위 목록을 그대로 사용한다. 기존 목록에만 있던 `일반업무추진비`, `기간제직원인건비` 등은 제거하며 합치지 않는다.

## 데이터 구조 및 동작

- 현재 `DEFAULT_ACCOUNT_CATEGORIES`를 위 20개 원가통계비목으로 교체한다.
- 각 항목은 화면 표시명과 간단한 용도 설명을 함께 가진 기존 데이터 형태를 유지한다.
- 콤보박스에는 표시명만 노출한다.
- 새 예산항목의 기본값은 `일반수용비`로 유지한다.
- 화면이 새로 열리거나 새 항목이 추가되면 `일반수용비`가 선택된다.
- 현재 화면 상태에 새 목록에 없는 값이 남아 있는 경우에는 첫 번째 항목인 `공무직인건비`로 정리한다. 현재 애플리케이션은 서버에 임시 항목을 저장하지 않으므로 새 배포를 다시 열면 기본값 `일반수용비`로 시작한다.

## 유지 범위

- 단위사업·세부사업 연동 콤보박스
- 세부항목 직접 입력
- 산출내역, 단가, 수량, 횟수 및 요구금액 계산
- 항목 추가·삭제와 합계 계산

## 테스트 및 검증

- 원가통계비목 목록이 정확히 20개인지 검증한다.
- 20개 항목의 명칭과 순서가 확정 목록과 완전히 일치하는지 검증한다.
- `일반수용비`가 새 예산항목의 기본 선택값인지 검증한다.
- 기존 목록에서 제거된 `일반업무추진비`, `기간제직원인건비`가 표시되지 않는지 검증한다.
- 전체 테스트와 TypeScript·Vite 빌드를 실행한다.

## 배포 원칙

수정과 검증 후 `vercel deploy`로 Preview만 배포한다. 사용자가 Preview를 확인하고 별도로 운영 배포를 승인하기 전에는 `--prod`, `promote`, 운영 도메인 연결을 실행하지 않는다.

## 완료 기준

- 원가통계비목 콤보박스에 확정된 20개 항목만 지정된 순서로 표시된다.
- 새 예산항목의 기본값은 `일반수용비`다.
- 기존 성립전예산 기능에 회귀가 없다.
- 전체 테스트와 빌드가 통과한다.
- Vercel Preview에서 사용자 확인이 가능하다.

# 본예산 업무추진비 3% 분석 개선 설계

## 목적

K-에듀파인 예산서현황에서 `세입예산명세서`와 `세출예산명세서`를 함께 선택해 내려받은 Excel 파일만으로 업무추진비 3% 편성 여부를 계산한다. `세입세출예산총괄` 구역은 더 이상 필수 입력으로 요구하지 않는다.

## 지원 입력

- Excel `.xls`, `.xlsx`
- 한 파일 안에 세입예산명세서와 세출예산명세서가 함께 포함된 형태
- 기존처럼 세입세출예산총괄까지 포함된 전체 예산서도 계속 지원
- 제공된 표본:
  - 2026년 `옥정.xls`
  - 2026년 `옥정2.xls`
  - 2026년 `옥정추가 xlsx.xlsx`
  - 2025년 `옥정2025.xlsx`

PDF 입력 안내와 분석 경로는 제거하고 Excel만 받는다.

## 에듀파인 다운로드 안내

업로드 화면에 아래 경로를 단계별로 표시한다.

1. 학교회계
2. 예산관리
3. 예산현황(학교)
4. 예산서현황
5. 세입세출예산총괄에서 `세입예산명세서`와 `세출예산명세서`를 모두 선택
6. Excel로 다운로드

사용자가 제공한 화면 이미지를 안내 영역에 표시한다. 모바일에서는 단계가 세로로 정렬되고 이미지는 화면 폭에 맞춰 축소한다.

## 파일 인식 방식

행 번호와 열 번호를 고정하지 않는다. 다음 표제와 구역 경계를 찾아 각 파일의 실제 위치를 결정한다.

- `세입예산명세서`
- `세출예산명세서`
- `예산액`
- `원가통계비목`
- `산출기초(원)`
- `세입합계`
- `세출합계`

세입과 세출 구역은 각각 자체 머리글을 기준으로 금액 열을 선택한다. 따라서 2025년과 2026년 파일처럼 예산액 열과 전체 행 수가 달라도 동일하게 처리한다. 학교명은 문서에서 확인되는 경우 표시하고, 학교명이 없는 명세서 파일은 파일명과 회계연도를 사용해 분석을 계속할 수 있도록 한다. 회계연도와 본예산 구분은 제목 및 예산구분 셀에서 확인한다.

## 세입 계산

세입 기준금액은 아래 8개 항목의 예산액 합계로 계산한다.

1. 학교운영비전입금
2. 사용료
3. 수수료
4. 자산매각대
5. 지난년도수입
6. 이자수입
7. 기타행정활동수입
8. 순세계잉여금

문서에 항목이 명시적으로 없으면 0원으로 처리한다. 항목은 있으나 금액을 읽지 못한 경우에만 확인 필요 경고를 표시한다. `세입합계 - 목적사업비 - 수익자부담금` 계산이나 원본 세입합계와의 대조는 수행하지 않는다.

## 세출 계산

세출예산명세서에서 원가통계비목명이 정확히 `일반업무추진비`인 행만 모은다. 구역별 머리글에서 찾은 예산액 열의 값을 천원 단위로 합산한다. 산출기초의 원 단위 금액은 참고 정보로만 사용하고 합계 계산에는 예산액 열을 사용한다.

편성 비율은 다음 식으로 계산한다.

`일반업무추진비 합계 ÷ 세입 검증 8개 항목 합계 × 100`

세입 기준금액이 0원이거나 필요한 금액을 읽지 못한 경우에는 비율 대신 확인 필요를 표시한다.

## 결과 화면

상단 분석 결과에는 다음 세 항목만 표시한다.

- 세입 기준금액: 세입 검증 8개 항목 합계
- 일반업무추진비 합계
- 편성 비율

`원본 세입합계 대조`, 일치·불일치 상태, 원본 계산값, 차이 금액 영역은 삭제한다. 이에 연결된 불일치 경고도 생성하지 않는다.

세입 검증 항목 표에는 8개 항목을 표시하고 마지막에 합계 행을 추가한다. 합계는 천원과 원 단위를 함께 표시한다.

일반업무추진비 세부 내역 표에도 마지막에 합계 행을 추가한다. 합계는 천원과 원 단위를 함께 표시한다. 표 위의 건수 표시는 유지한다.

## 오류 처리

- Excel이 아니면 `.xls 또는 .xlsx 파일을 선택해 주세요`라고 안내한다.
- 세입예산명세서 또는 세출예산명세서가 없으면 누락된 구역을 구체적으로 안내한다.
- 항목은 있으나 예산액 열이나 금액을 판별하지 못한 경우 해당 항목과 출처 행을 경고에 표시한다.
- 총괄표가 없다는 이유만으로 분석을 중단하지 않는다.

## 기존 기능 호환

- 기존 전체 예산서 Excel 분석을 유지한다.
- 분석 결과 임시저장과 다음 방문 복원 기능을 유지한다.
- 기존 경고 묶기, 학교·회계연도·본예산 표시, 다른 파일 분석 기능을 유지한다.
- 결과 저장 형식이 변경될 경우 과거 저장 자료를 안전하게 무시하거나 변환하여 화면 오류를 방지한다.

## 검증

- 네 개 제공 표본 모두에서 세입 8개 항목과 일반업무추진비 내역을 추출한다.
- 2025년과 2026년의 서로 다른 예산액 열을 각각 올바르게 선택한다.
- `.xls`와 `.xlsx` 결과가 같은 원칙으로 계산되는지 확인한다.
- 총괄표가 없는 상세 명세서 파일이 성공하고, 세입 또는 세출 명세서가 없는 파일은 실패하는지 확인한다.
- 세입 표와 일반업무추진비 표의 합계가 상세 행 합계와 일치하는지 확인한다.
- 원본 세입합계 대조 문구와 불일치 경고가 화면 및 계산 결과에서 사라졌는지 확인한다.
- 업로드 안내 경로와 이미지가 데스크톱·모바일 레이아웃에 포함되는지 확인한다.
- 전체 자동 점검과 배포용 빌드를 통과한 뒤 GitHub 저장 및 공개 사이트 배포를 진행한다.

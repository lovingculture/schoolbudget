# 예산 안건설명서 가독성 및 드래그 업로드 수정 설계

## 목적

예산 안건설명서 입력 화면과 출력 미리보기의 글자 가독성을 높이고, 사용자가 큰 업로드 상자에 엑셀 파일을 끌어다 놓았을 때 정상적으로 불러오도록 한다.

## 입력 화면

- `제안정보`, `총 규모` 등 편집 구역 제목은 20px로 표시한다.
- 입력 항목명은 14px로 표시한다.
- 일반 입력칸과 제안이유·근거 등 긴 내용 입력란은 16px로 표시한다.
- 세입·세출예산 편집표의 입력 글자는 14px로 표시한다.
- `원본값` 안내는 12px로 표시한다.
- 기존 입력 구조, 값, 계산 방식은 변경하지 않는다.

## 출력 미리보기

- 제안이유 본문을 12px로 표시한다.
- 근거 본문을 12px로 표시한다.
- 추경예산 편성 주요내용의 번호와 본문을 12px로 표시한다.
- 항목 제목과 표의 일반 숫자 표시는 기존 크기를 유지한다.
- 세입예산의 긴 항목명 `지방교육행정기관이전수입`은 해당 셀 안에서 읽히도록 글자 크기를 조정하고 줄바꿈을 허용한다.
- 다른 셀과 문구의 크기에는 영향을 주지 않는다.

## 드래그 업로드

- 현재 드롭 이벤트가 작은 안내문 영역에만 연결된 문제를 수정한다.
- 큰 점선 업로드 상자 전체를 실제 드롭 영역으로 사용한다.
- 파일을 끌어 올렸을 때 테두리와 배경색으로 드래그 상태를 표시한다.
- 드롭한 첫 번째 엑셀 파일을 기존 파서로 전달한다.
- 버튼을 눌러 파일을 선택하는 기존 방식도 유지한다.
- 지원 형식과 파싱 오류 안내는 기존 동작을 유지한다.

## 검증

- 드래그 업로드를 재현하는 컴포넌트 테스트를 먼저 추가하고 실패를 확인한다.
- 수정 후 같은 테스트와 관련 예산 안건설명서 테스트를 실행한다.
- 전체 앱 빌드를 실행한다.
- Vercel Preview 배포 상태가 `READY`인지 확인한다.

## 배포 제한

- 대상은 Vercel `school-budget-portal` 프로젝트다.
- Preview 배포만 수행한다.
- 운영 배포, 운영 별칭 변경, Preview의 운영 승격은 수행하지 않는다.

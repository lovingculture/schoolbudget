# 실제 에듀파인 결산자료 및 결산안 예시 일치 설계

## 목적

실제 에듀파인 `세입세출결산총괄표.xls`을 웹에서 드래그하거나 선택했을 때 결산 데이터를 정상적으로 읽고, 제공된 결산 심의안건 PDF와 같은 내용 구조의 A4 세로 2쪽 문서를 자동 작성한다.

## 원본 데이터 기준

- 학년도, 학교명, 총괄 금액, 세계잉여금 처리 금액, 세입 장·관, 세출 정책사업명은 에듀파인 원본을 기준으로 한다.
- 원본 마지막 정책사업인 `학교시설 확충`을 그대로 표시한다.
- PDF 예시의 `학교 재무활동` 문구로 임의 변환하지 않는다.
- 숫자는 원 단위 정수로 보관하고 화면과 문서에서 천 단위 쉼표로 표시한다.

## 파서 변경

- 실제 원본에는 세입·세출 결산내역의 `구성비` 열이 없으므로 필수 열로 요구하지 않는다.
- 세입 구성비는 각 관 결산액을 세입결산액으로 나누어 백분율로 계산한다.
- 세출 구성비는 각 정책사업 결산액을 세출결산액으로 나누어 백분율로 계산한다.
- 구성비는 소수점 첫째 자리까지 반올림한다.
- 합계가 0이면 구성비를 0으로 처리하여 0 나누기 오류를 방지한다.
- 구성비 열이 있는 다른 에듀파인 변형 파일도 계속 지원하되, 계산값을 기준으로 일관되게 표시한다.
- `.xls`와 `.xlsx`를 모두 지원한다.

## 자동작성 내용

- 제목: `YYYY학년도 학교회계 세입·세출 결산(안)`
- 제안 근거와 제안 이유는 기존 기본문구를 유지한다.
- 총괄표에는 예산액, 예산현액, 세입결산액, 세출결산액, 세계잉여금을 표시한다.
- 세계잉여금 처리 현황에는 사고이월, 명시이월, 계속비이월, 순세계잉여금을 표시한다.
- 세입 결산내역에는 원본의 장·관·결산액과 계산한 구성비를 표시한다.
- 세출 결산내역에는 원본의 정책사업·결산액과 계산한 구성비를 표시한다.
- 제안연월일, 안건번호, 제안자, 제안설명자, 근거, 이유, 표 내용, 별첨 문구를 사용자가 수정할 수 있는 기존 기능을 유지한다.

## 출력 형식

- A4 세로 2쪽 구성을 유지한다.
- 1쪽은 제목, 제안정보, 제안 근거, 제안 이유, 총괄표, 세계잉여금 처리 현황으로 구성한다.
- 2쪽은 세입표, 세출표, 별첨 문구로 구성한다.
- 결산액은 천 단위 쉼표, 구성비는 소수점 한 자리로 표시한다.
- 원본 장이 연속되는 세입 행에서는 웹 접근성을 해치지 않는 범위에서 PDF 예시처럼 시각적으로 묶어 표시한다.

## 검증

- 제공된 실제 `세입세출결산총괄표(3).xls`을 회귀 테스트 fixture로 사용한다.
- 총괄 금액과 세입·세출 각 행의 결산액이 원본과 일치하는지 검사한다.
- `학교시설 확충`이 그대로 유지되는지 검사한다.
- 세입·세출 구성비가 원본 금액으로 계산되어 PDF 예시 수준의 소수점 한 자리 값과 일치하는지 검사한다.
- 기존 변형 보고서 거절 테스트와 결산 편집·미리보기·내보내기 테스트를 실행한다.
- 전체 빌드를 실행한다.

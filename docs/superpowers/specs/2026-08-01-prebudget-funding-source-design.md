# 성립전예산 재원구분 콤보박스 변경 설계

## 목표

성립전예산 기본정보의 `재원` 항목명을 `재원구분`으로 변경하고, 기존 네 가지 선택지를 사용자가 지정한 세 가지 재원구분으로 완전히 교체한다.

## 확정 목록과 순서

1. `보조금(구청)`
2. `목적사업비(교육청)`
3. `수익자부담경비(학부모)`

기존 `교육청`, `서울시`, `자치구`, `기타` 선택지는 모두 제거한다.

## 화면 및 데이터 동작

- 입력 항목의 표시명을 `재원구분`으로 변경한다.
- 콤보박스에는 확정된 세 가지 항목만 지정된 순서로 표시한다.
- 기본 선택값은 두 번째 항목인 `목적사업비(교육청)`으로 설정한다.
- 괄호 설명을 포함한 전체 문구를 선택값으로 저장한다.
- 이후 기안문과 파일 생성 기능이 연결되면 `보조금(구청)`처럼 전체 문구를 그대로 사용할 수 있게 한다.

## 유지 범위

- 회계연도, 문서 제목, 부서명, 요구자, 관련 공문 입력
- 단위사업·세부사업 연동
- 세부항목, 원가통계비목 20개, 산출내역 및 금액 계산
- 예산항목 추가·삭제와 합계

## 테스트 및 검증

- 화면에 `재원구분` label이 표시되는지 검증한다.
- 기본 선택값이 `목적사업비(교육청)`인지 검증한다.
- 옵션이 정확히 세 개이며 지정된 순서인지 검증한다.
- 기존 `교육청`, `서울시`, `자치구`, `기타` 옵션이 표시되지 않는지 검증한다.
- 전체 테스트와 TypeScript·Vite 빌드를 실행한다.

## 배포 원칙

수정과 검증 후 `vercel deploy`로 Preview만 배포한다. 사용자가 Preview를 확인하고 별도로 운영 배포를 승인하기 전에는 `--prod`, `promote`, 운영 도메인 연결을 실행하지 않는다.

## 완료 기준

- `재원구분` 콤보박스에 확정된 세 항목만 지정 순서로 표시된다.
- 기본 선택값이 `목적사업비(교육청)`이다.
- 기존 성립전예산 기능에 회귀가 없다.
- 전체 테스트와 빌드가 통과한다.
- Vercel Preview에서 사용자 확인이 가능하다.

# 집행실적 추경자료 Excel 양식 일치 설계

## 목표

에듀파인 집행실적 엑셀저장(실시간) 102-2 파일을 웹앱에 넣으면, 사용자가 제공한 `집행실적정리용엑셀 확정본(2).xlsm`의 결과 표와 동일한 구조·표현을 가진 매크로 없는 `.xlsx` 파일을 내려받게 한다.

## 기준 자료

- 입력 검증 파일: `2026집행실적_102-2_20260801180031440(1).xlsx`
- 출력 기준 파일: `집행실적정리용엑셀 확정본(2).xlsm`
- 기준 파일의 결과 시트: `불러온원본`, `추경검토`, `정리본`, `단위사업별집계`
- 최종 다운로드에서는 빈 `Sheet1`, 도형 버튼, VBA 프로젝트를 제외한다.

## 선택한 구현 방식

브라우저에서 기준 파일과 동일한 결과 통합문서를 새로 생성한다. 매크로 파일 자체를 실행하거나 그대로 배포하지 않고, 기준 파일에서 확인한 시트 구조·표 머리글·열 너비·행 높이·서식·수식·필터·틀 고정·인쇄 설정을 웹용 Excel 생성 코드에 명시한다.

이 방식은 학교 PC에서 매크로 보안 경고 없이 열리고, 입력 행 수가 달라져도 표와 합계 범위를 안전하게 확장할 수 있다.

## 데이터 흐름

1. 사용자가 102-2 `.xls`, `.xlsx`, `.xlsm` 파일을 선택하거나 드래그한다.
2. 기존 파서가 학교명, 회계연도, 집행기준일과 원본 행을 읽고 필수 102-2 열을 검증한다.
3. 계산 계층이 예산액, 원인행위금액, 지출금액, 집행잔액, 원인행위·지출 불일치, 집행률을 계산한다.
4. 화면에서 사용자가 입력한 부서별 집행예정액과 추경(안)을 계산 결과에 합친다.
5. Excel 생성 계층이 네 시트를 기준 파일 순서로 만들고 `.xlsx`로 저장한다.

## 시트별 요구사항

### 1. 불러온원본

- 에듀파인 원본의 제목과 전체 열·행을 보존한다.
- 기준 파일과 동일한 제목 병합, 머리글 표현, 테두리, 필터와 열 너비를 적용한다.
- 데이터 변환의 추적 근거이므로 원본 값을 임의로 축약하지 않는다.

### 2. 추경검토

- 시트명은 정확히 `추경검토`로 한다.
- 기준 파일의 A:O 15개 열 순서와 제목을 그대로 사용한다.
- 사용자 입력값인 부서별 집행예정액과 추경(안)을 숫자 셀로 기록한다.
- 추경 가능금액은 `집행잔액 - 부서별 집행예정액`으로 산출한다.
- 마지막 합계 행을 만들고 기준 파일처럼 A:H를 병합한다.
- 머리글, 본문, 합계 행의 글꼴·채우기·테두리·정렬·숫자 형식을 재현한다.

### 3. 정리본

- 시트명은 정확히 `정리본`으로 한다.
- 기준 파일의 A:O 열 순서와 표 구현 방식을 따른다.
- 제목은 `예산집행현황`으로 표시한다.
- 예산현액은 102-2의 예산액(4) 값을 사용한다.
- 집행잔액은 `예산현액 - 원인행위금액`, 불일치는 `원인행위금액 - 지출금액`으로 계산한다.
- 집행률은 `원인행위금액 / 예산현액`이며 0으로 나누는 경우 0%로 표시한다.
- 집행잔액 음수는 빨간색으로 표시한다.
- 마지막 합계 행, 자동필터, 틀 고정, 맑은 고딕, 열 너비, 행 높이, 숫자 및 백분율 형식을 기준 파일과 맞춘다.

### 4. 단위사업별집계

- 시트명은 정확히 `단위사업별집계`로 한다.
- 제목은 `단위사업별 집행현황`으로 표시하고 A1:F1을 병합한다.
- 열은 `정책사업`, `단위사업`, `세부사업`, `예산액`, `원인행위금액`, `집행률` 순서로 한다.
- 정책사업·단위사업·세부사업별로 집계하고 마지막에 `총합계`를 둔다.
- 집행률은 합계 원인행위금액을 합계 예산액으로 나누어 계산한다.
- 기준 파일의 머리글, 본문, 합계, 필터 범위, 백분율 형식을 재현한다.

## 동적 행 처리

- 기준 파일의 527행에 고정하지 않는다.
- 입력 데이터 수에 따라 본문 행과 합계 행 위치를 계산한다.
- 본문 각 행에 동일한 서식과 수식 패턴을 적용한다.
- 필터, 병합, 틀 고정, 인쇄영역과 합계 수식은 마지막 데이터 행을 기준으로 갱신한다.

## 화면 동작

- 현재 웹 화면의 네 결과 탭과 사용자 입력 기능은 유지한다.
- `Excel 다운로드` 버튼은 새 양식 생성기만 호출한다.
- 화면 검색으로 일시적으로 숨긴 행과 무관하게, 다운로드에는 전체 데이터와 사용자 입력값을 포함한다.
- 파일명은 `<회계연도>_<학교명>_추경검토자료.xlsx`로 유지한다.

## 오류 처리

- 필수 102-2 열이 없으면 기존 안내 문구로 다운로드를 차단한다.
- 숫자가 비어 있으면 계산용 0으로 처리하되 원본 시트 값은 보존한다.
- 예산액이 0이면 집행률은 0%로 표시한다.
- 다운로드 생성 실패 시 사용자에게 다시 시도하도록 명확한 오류를 표시한다.

## 검증 기준

- 실제 102-2 입력 파일로 결과를 생성한다.
- 시트명과 순서가 `불러온원본`, `추경검토`, `정리본`, `단위사업별집계`인지 검사한다.
- 기준 파일과 각 시트의 제목, 열 제목, 열 순서, 데이터 행 수, 합계값, 주요 수식을 비교한다.
- 대표 행에서 예산액·원인행위·지출·잔액·불일치·집행률을 대조한다.
- 음수 빨간색, 숫자/백분율 형식, 병합, 열 너비, 행 높이, 필터, 틀 고정과 인쇄 설정을 검사한다.
- Excel에서 네 시트를 시각적으로 열어 잘림, 깨진 제목, 누락된 테두리, 잘못된 합계가 없는지 확인한다.
- 기존 파서·계산·화면 테스트 전체를 다시 실행하고 운영 빌드를 통과시킨다.

## 배포

구현과 검증이 끝난 뒤 미리보기 배포에서 실제 다운로드 파일을 확인한다. 사용자가 미리보기를 승인하면 기존 `school-budget-portal` 운영 프로젝트에 배포한다.

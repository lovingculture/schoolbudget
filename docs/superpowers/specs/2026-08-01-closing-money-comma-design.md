# 결산설명서 금액 입력 쉼표 표시 설계

## 목표

결산설명서 웹 편집 화면의 모든 금액 입력칸에 세 자리 단위 쉼표를 표시한다. 사용자가 숫자를 입력하거나 수정할 때도 읽기 쉬운 형식을 유지하면서, 내부 상태와 검증·문서 출력에는 기존과 동일한 숫자값을 전달한다.

## 적용 범위

- 세입·세출 결산 총괄표: 예산액, 예산현액, 세입결산액, 세출결산액, 세계잉여금
- 세계잉여금 처리 현황: 사고이월, 명시이월, 계속비이월, 보조금반환 확정액, 순세계잉여금
- 세입 결산내역: 각 행의 결산액
- 세출 결산내역: 각 행의 결산액

회계연도와 구성비 입력칸에는 금액 쉼표 처리를 적용하지 않는다.

## 입력 동작

- 금액 입력칸은 쉼표 표시를 위해 `type="text"`와 숫자 입력 키보드 힌트인 `inputMode="numeric"`를 사용한다.
- 표시값은 정수에 `ko-KR` 세 자리 쉼표를 적용한다. 예: `2727447000` → `2,727,447,000`.
- 사용자가 입력한 문자열에서는 맨 앞의 음수 기호를 제외한 쉼표와 숫자가 아닌 문자를 제거한 뒤 숫자로 변환한다.
- 입력칸을 모두 지운 상태는 숫자 `0`으로 반영한다.
- 음수 값은 앞의 `-`를 유지하고 절댓값에 쉼표를 적용한다.
- 원본값 복원 버튼과 수정됨 표시는 현재 숫자 비교 방식을 유지한다.

## 데이터 흐름

표시용 문자열은 공통 `MoneyInput` 컴포넌트 안에서만 만든다. 컴포넌트의 `onChange`는 항상 `number`를 반환한다. 따라서 `ClosingAgendaDraft`, 정합성 검사, 미리보기, PDF·Word·Excel 출력기의 자료형과 계산 로직은 변경하지 않는다.

## 구성요소

- `formatEditableMoney(value: number): string`: 0을 `0`으로, 나머지 정수를 쉼표 문자열로 변환한다.
- `parseEditableMoney(value: string): number`: 입력 문자열을 정수 숫자로 변환한다.
- `MoneyInput`: 접근 가능한 라벨을 유지하고 두 함수를 사용해 표시와 변경을 연결한다.
- 기존 `NumberField`와 세입·세출 행의 결산액 입력칸은 `MoneyInput`을 재사용한다.

## 오류와 경계값

- 빈 문자열과 숫자가 없는 문자열은 0으로 처리한다.
- 소수점은 금액 입력에서 제거한다.
- 자릿수가 큰 경우에도 JavaScript 안전 정수 범위 안에서 기존 숫자 계산을 유지한다.
- 구성비 입력은 기존 `type="number"`, `step="0.1"`을 유지한다.

## 검증 기준

- 초기 화면에 `2,727,447,000`, `361,675,980`, `135,260,610`처럼 쉼표가 표시된다.
- 쉼표가 포함된 값을 수정하면 부모 상태에는 숫자가 전달된다.
- 원본값 복원 후 쉼표 표시와 숫자값이 모두 원래대로 돌아온다.
- 세입·세출 결산액 입력과 구성비 입력이 서로 영향을 주지 않는다.
- 결산 기능 전체 테스트와 운영 빌드를 통과한다.
- Vercel 미리보기에서 확인받은 후에만 운영 배포한다.

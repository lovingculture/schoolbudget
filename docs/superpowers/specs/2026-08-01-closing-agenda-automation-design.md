# 결산 안건설명서 자동화 설계

## 1. 목표

학교 사용자가 에듀파인에서 내려받은 `세입세출결산총괄표` 엑셀 파일을 웹페이지에 끌어다 놓으면 결산자료를 자동으로 분석하고, 사용자가 모든 내용을 검토·수정한 뒤 공식 결산 안건설명서를 PDF·Word·Excel로 내려받을 수 있게 한다.

기준 출력물은 사용자가 제공한 `1.(심의안건) 2025학년도 학교회계 세입세출 결산 (안)(3).pdf`이며 A4 세로 2쪽 구성을 따른다.

## 2. 사용자 흐름

1. 왼쪽 메뉴에서 `결산설명서`를 선택한다.
2. 업로드 영역에서 에듀파인 다운로드 경로를 확인한다.
3. `.xls` 또는 `.xlsx` 파일을 끌어다 놓거나 `파일 선택` 버튼으로 불러온다.
4. 웹앱이 파일 종류와 필수 항목을 검사한다.
5. 정상 파일이면 학년도·학교명·결산금액과 검증 결과를 표시한다.
6. 사용자가 제안정보와 자동 추출된 모든 내용을 검토·수정한다.
7. A4 2쪽 미리보기를 확인한다.
8. PDF·Word·Excel 중 원하는 파일을 각각 내려받는다.

## 3. 업로드 영역

업로드 영역에는 다음 안내를 항상 표시한다.

> 에듀파인 「세입세출결산총괄표」를 여기에 끌어다 놓으세요
>
> 다운로드 경로  
> 학교회계 → 예산결산 → 결산서 → 결산서 일괄 출력 → 세입세출결산총괄표 → 엑셀 다운로드
>
> 지원 파일: .xls, .xlsx  
> 반드시 에듀파인에서 내려받은 세입세출결산총괄표를 사용해 주세요.

드래그 중에는 테두리와 배경색을 변경한다. 드래그 사용이 어려운 사용자를 위해 `파일 선택` 버튼을 함께 제공한다.

## 4. 원본 판별과 자동 추출

### 4.1 원본 판별

- 시트명 `세입세출결산총괄표` 확인
- 제목에서 `YYYY년도 학교회계 결산총괄표` 확인
- 총괄표, 잉여금 처리현황, 세입 결산내역, 세출 결산내역의 핵심 표제 확인
- 필수 금액 셀이 숫자인지 확인

시트 위치가 조금 달라도 표제어를 먼저 찾아 읽고, 사용자가 제공한 현재 에듀파인 양식에서는 알려진 셀 위치를 보조 기준으로 사용한다.

### 4.2 자동 추출 항목

- 학년도와 학교명
- 예산액, 예산현액
- 세입결산액, 세출결산액, 세계잉여금
- 명시이월, 사고이월, 계속비이월
- 보조금반환 확정액
- 결산 전 이입, 결산 후 이월, 순세계잉여금
- 세입 장·관별 결산액과 구성비
- 세출 정책사업별 결산액과 구성비

### 4.3 자동 검증

- 세입결산액 - 세출결산액 = 세계잉여금
- 세입 결산내역 합계 = 세입결산액
- 세출 결산내역 합계 = 세출결산액
- 이월·반환·순세계잉여금 관계 점검

검증 결과는 `정상`, `확인 필요`로 표시한다. 불일치가 있어도 사용자가 원문을 확인하고 계속 편집할 수 있으며, 파일 생성 직전에 다시 경고한다.

## 5. 편집 화면

### 5.1 직접 입력 항목

- 제안연월일
- 안건번호
- 제안자
- 제안설명자

기본값은 제안자 `학교장`, 제안설명자 `행정실장`로 제시하되 사용자가 변경할 수 있다.

### 5.2 수정 가능한 자동 작성 항목

- 문서 제목
- 제안 근거
- 제안 이유
- 총괄표의 모든 제목·금액
- 세계잉여금 처리 현황의 구분·종류·금액·비고
- 세입·세출 결산내역의 사업명·금액·구성비
- 별첨 문구

자동 추출값을 수정한 셀은 `수정됨` 표시를 제공한다. `원본값으로 되돌리기` 기능으로 자동 추출 당시 값으로 복구할 수 있다.

## 6. 미리보기와 출력

### 6.1 화면 미리보기

- A4 세로 비율
- 1쪽: 제목, 안건번호, 제안정보, 제안 근거·이유, 주요 내용, 총괄표, 세계잉여금 처리 현황
- 2쪽: 세입 결산내역, 세출 결산내역, 별첨
- 금액은 천 단위 쉼표를 적용하고 0원은 기준 PDF처럼 `-`로 표시할 수 있다.

### 6.2 PDF

- 제출용 A4 세로 2쪽
- 기준 PDF의 제목·표·여백·구획을 최대한 동일하게 구현
- 한글 폰트를 포함해 다른 컴퓨터에서도 글자가 깨지지 않게 생성

### 6.3 Word

- PDF와 같은 문서 구조
- 제목, 제안정보, 본문, 표를 Word에서 다시 수정 가능
- `.docx` 형식

### 6.4 Excel

- `입력·검증` 시트: 원본 파일명, 추출값, 검증 결과
- `심의안건` 시트: 출력용 A4 2쪽 서식
- 자동 계산값은 가능한 범위에서 수식으로 유지
- `.xlsx` 형식

파일명 기본값은 `1.(심의안건) YYYY학년도 학교회계 세입세출 결산 (안)`으로 하고 확장자만 각각 다르게 한다.

## 7. 개인정보와 저장

- 원본 엑셀 파일은 브라우저 안에서만 읽는다.
- 원본 파일과 생성 문서는 서버에 자동 업로드하거나 저장하지 않는다.
- 사용자가 내려받은 파일은 사용자의 컴퓨터에만 저장된다.
- 카카오 로그인이 비활성화된 현재 상태에서도 기능을 사용할 수 있다.

## 8. 오류 처리

- 잘못된 확장자: 지원 형식 안내
- 다른 보고서: `에듀파인 세입세출결산총괄표가 아닙니다` 안내
- 필수 항목 누락: 찾지 못한 항목명을 표시
- 손상된 파일: 새로 다운로드한 원본으로 재시도 안내
- 합계 불일치: 항목별 원본값과 계산값을 함께 표시
- 생성 실패: 입력 내용은 유지하고 해당 형식만 다시 생성 가능

## 9. 구현 경계

이번 단계에는 결산 안건설명서의 업로드·검증·전체 편집·미리보기·PDF/Word/Excel 생성까지 포함한다. 결산서 및 부속자료 전체 묶음 업로드, 전자결재 직접 전송, 학교별 서버 저장과 공동편집은 포함하지 않는다.

## 10. 완료 기준

- 제공된 `세입세출결산총괄표(2).xls`를 브라우저에서 정상 분석한다.
- 제공된 기준 PDF와 같은 정보가 A4 2쪽에 빠짐없이 출력된다.
- 제안정보를 포함한 모든 자동 작성 항목을 수정할 수 있다.
- 세 가지 핵심 합계 검증이 정확하다.
- PDF·Word·Excel 파일이 모두 열리고 한글과 표가 깨지지 않는다.
- 데스크톱과 모바일에서 업로드 및 편집 흐름을 사용할 수 있다.
- 원본 파일이 서버로 전송되지 않는다.

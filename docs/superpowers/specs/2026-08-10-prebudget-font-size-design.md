# 성립전예산 작성 화면 글자 크기 개선 설계

## 목표

성립전예산 작성 화면의 기본정보, 예산항목, 안내문을 학교 행정실 PC 환경에서 편하게 읽을 수 있도록 확대한다. 사용자가 제시한 `예시를 복사한 초안입니다` 수준의 가독성을 기준으로 삼되, 모든 문구를 동일하게 18px로 키워 화면이 답답해지는 것은 피한다.

## 적용 범위

- 성립전예산 직접 작성 화면에만 전용 클래스(`prebudget-page`)를 적용한다.
- 다른 업무 화면, 사이드바, 홈, 자료실의 공통 글자 크기는 변경하지 않는다.
- 기본정보와 예산항목의 데이터 구조, 자동계산, 예시 불러오기, 임시저장, 문서 생성 기능은 변경하지 않는다.
- 데스크톱의 기본정보 2열·예산항목 3열 구조와 모바일 1열 구조를 유지한다.

## 글자 크기 체계

- 입력 항목 라벨: 16px
- 입력창·선택창의 입력값: 16px
- 입력창·선택창 높이: 최소 50px 수준으로 확보
- 비목 설명 제목: 16px
- 비목 설명 본문과 일반 보조 설명: 15px, 충분한 줄 간격 적용
- `예시를 복사한 초안입니다`, `자동점검 결과` 등 중요 안내 제목: 18px
- 중요 안내의 본문·목록: 15px 이상
- 예산항목 제목과 주요 버튼: 18~20px 범위
- 계산 금액과 예산요구액 합계는 현재 강조 체계를 유지하되 주변 글자도 읽기 쉽게 조정

## 구현 방식

1. `PrebudgetPage`의 직접 작성 화면 최상위 요소에 `prebudget-page` 클래스를 추가한다.
2. `styles.css`에 `.prebudget-page` 아래로만 적용되는 글자·높이 규칙을 추가한다.
3. 기존 공통 선택자인 `.form-grid`, `.item-fields`, `.card-title-row`의 전역 크기는 수정하지 않는다.
4. 모바일에서는 글자 크기를 다시 작게 줄이지 않고, 기존 열 전환과 여백 조정만 유지한다.
5. 입력창 높이 증가로 줄바꿈이나 가로 넘침이 발생하지 않도록 기존 반응형 레이아웃을 확인한다.

## 검증

- 성립전예산 작성 화면에 `prebudget-page` 범위가 적용되는지 테스트한다.
- 라벨, 입력값, 비목 설명, 중요 안내에 합의한 최소 글자 크기가 적용되는지 CSS 회귀 테스트를 추가한다.
- 예시 불러오기 이후 수정, 금액 자동계산, 임시저장, 기안문 생성 테스트가 계속 통과하는지 확인한다.
- 전체 테스트와 빌드를 실행한다.
- 데스크톱과 좁은 화면에서 글자가 겹치거나 입력창이 잘리지 않는지 실제 화면으로 확인한다.

## 제외 사항

- 포털 전체 글꼴이나 기본 배율 변경
- 학교 설정 저장 문제 수정
- 성립전예산 데이터·문서 양식 변경
- 운영 환경 배포

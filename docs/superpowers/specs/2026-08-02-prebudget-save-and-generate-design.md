# 성립전예산 임시저장·자동점검·기안문 생성 설계

## 목표

현재 표시만 되고 동작하지 않는 `임시저장`과 `자동점검 후 기안문 생성` 버튼을 실제 기능으로 연결한다. 사용자가 작성 중인 성립전예산을 현재 브라우저에 저장·복원하고, 입력 내용을 자동점검한 뒤 K-에듀파인 복사용 일반 기안문을 화면에서 확인하고 Word·PDF·Excel로 내려받을 수 있게 한다.

## 현재 문제와 원인

- 두 버튼에는 클릭 처리 함수가 연결되어 있지 않다.
- 기본정보 입력값은 비제어 입력이라 저장·검증·문서 생성 데이터에 포함되지 않는다.
- 예산항목은 화면 상태에만 있으며 저장소와 연결되어 있지 않다.
- 성립전예산용 미리보기와 Word·PDF·Excel 생성 모듈이 없다.
- 카카오 로그인은 현재 코드에서 비활성화되어 있으므로 사용자 계정별 서버 저장은 사용할 수 없다.

## 확정 범위

- 이번 단계에서는 로그인 기능을 켜지 않는다.
- 임시저장은 현재 브라우저의 `localStorage`에 최신 초안 1개를 저장한다.
- 다른 PC나 다른 브라우저에서는 저장 초안을 불러올 수 없다.
- 저장 인터페이스를 분리하여 추후 Supabase 사용자 계정 저장소로 교체할 수 있게 한다.
- 기안문은 우선 K-에듀파인 복사용 일반 형식으로 만든다.
- 결과는 화면 미리보기, 전체 복사, Word, PDF, Excel을 제공한다.
- 공식 기안문 양식을 나중에 받으면 미리보기와 출력 템플릿만 교체할 수 있게 분리한다.
- 성립전예산 기본정보에 사용자가 직접 수정할 수 있는 `학교명` 입력칸을 추가한다.

## 입력 데이터 모델

`PrebudgetDraft`가 다음 값을 모두 관리한다. 학교명은 성립전예산 기본정보의 입력칸에서 수정할 수 있고, 초기값은 현재 포털에 전달된 학교명을 사용한다.

- 학교명
- 회계연도
- 재원구분
- 문서 제목
- 부서명
- 요구자
- 관련 공문
- 예산항목 배열
- 마지막 저장 시각

각 예산항목은 다음 값을 가진다.

- 단위사업
- 세부사업
- 세부항목
- 원가통계비목
- 산출내역
- 단가
- 수량
- 횟수
- 계산된 요구금액

기본정보 입력을 React 상태와 연결하여 입력·저장·검증·문서 생성이 같은 데이터를 사용하게 한다.

## 임시저장과 자동 복원

- 저장 키는 버전을 포함한 고정 키 `school-budget-portal:prebudget-draft:v1`을 사용한다.
- 현재 브라우저에는 최신 초안 1개만 저장하며 학교명은 초안 데이터 안에 포함한다.
- `임시저장` 클릭 시 현재 기본정보와 모든 예산항목을 JSON으로 저장한다.
- 저장 성공 후 버튼 주변에 `임시저장 완료`와 저장 시각을 표시한다.
- 저장 실패 시 `임시저장에 실패했습니다. 브라우저 저장공간을 확인해 주세요.`를 표시한다.
- 성립전예산 화면을 처음 열 때 저장 데이터가 있으면 학교명을 포함한 전체 초안을 자동 복원한다.
- 저장 데이터가 없거나 JSON이 손상되었으면 기본 초안으로 시작하고 화면 오류를 발생시키지 않는다.
- 저장소는 `load()`, `save()`, `clear()` 인터페이스를 가지며 이번 구현은 브라우저 저장소 어댑터를 사용한다.
- 추후 Supabase 어댑터는 동일 인터페이스로 교체한다.

## 빈 행 처리와 자동점검

### 완전히 빈 예산항목

단위사업, 세부사업, 세부항목, 산출내역이 비어 있고 단가·수량·횟수가 모두 0이면 완전히 빈 항목으로 판단한다. 원가통계비목은 기본값 `일반수용비`가 있어도 빈 항목 판단에 영향을 주지 않는다.

완전히 빈 항목은 다음에서 제외한다.

- 자동점검 오류
- 기안문 미리보기
- Word·PDF·Excel 출력
- 예산요구 총액

### 필수 점검

- 문서 제목
- 학교명
- 부서명
- 요구자
- 관련 공문
- 단위사업
- 세부사업
- 세부항목
- 원가통계비목
- 산출내역
- 요구금액 0원 초과

일부만 입력한 항목은 항목 번호와 누락 내용을 함께 안내한다. 오류가 하나라도 있으면 기안문 화면으로 이동하거나 파일을 생성하지 않는다.

## 기안문 미리보기

자동점검을 통과하면 같은 페이지의 입력 화면 아래에 K-에듀파인 복사용 일반 기안문을 표시하고 해당 영역으로 자동 이동한다. 사용자는 위 입력 내용을 수정한 뒤 다시 생성하여 미리보기를 갱신할 수 있다.

기안문은 다음 순서로 구성한다.

1. 문서 제목
2. 관련 공문
3. 성립전예산 편성 요청 문구
4. 회계연도와 재원구분
5. 예산요구 총액
6. 단위사업·세부사업·세부항목·원가통계비목·산출내역·요구금액 표
7. `붙임  성립전예산 요구내역 1부.  끝.` 문구

금액은 원 단위로 세 자리마다 쉼표를 표시한다. 미리보기에는 `기안문 전체 복사` 버튼을 두고 복사 성공·실패 안내를 표시한다.

## 파일 생성

### Word

- `.docx` 형식
- 기안문 제목, 본문, 예산요구 내역 표 포함
- 한글 문서에서 읽기 쉬운 글자 크기와 표 테두리 적용

### PDF

- 화면 미리보기 기반 A4 세로 출력
- 여러 페이지가 필요한 경우 표 행을 다음 페이지로 이어서 출력

### Excel

- `.xlsx` 형식
- `기안문` 시트: 제목, 관련 공문, 편성 내용과 총액
- `예산요구내역` 시트: 항목별 상세 데이터와 합계
- 숫자 셀은 숫자 형식으로 저장하고 천 단위 구분 표시

파일명은 `<회계연도>학년도_<학교명>_<문서제목>_성립전예산`을 기본으로 하며 운영체제에서 사용할 수 없는 문자는 제거한다.

## 화면 상태와 오류 처리

- `임시저장` 중에는 중복 클릭을 막고 `저장 중…`을 표시한다.
- 자동점검 오류는 버튼 위에 요약 상자로 표시한다.
- 오류 항목은 `1번 항목: 세부사업을 선택하세요.`처럼 안내한다.
- 문서 생성 중에는 다운로드 버튼을 비활성화하고 진행 상태를 표시한다.
- 파일 생성 실패 시 기존 입력값과 미리보기는 유지하고 오류 메시지만 표시한다.

## 코드 구조

성립전예산 기능을 `src/features/prebudget/` 아래로 분리한다.

- `types.ts`: 기본정보, 항목, 초안, 검증 오류 타입
- `draft.ts`: 기본 초안 생성, 빈 항목 판단, 출력 대상 항목 정리
- `storage.ts`: 저장소 인터페이스와 localStorage 어댑터
- `validation.ts`: 기본정보와 입력 항목 검증
- `createDocument.ts`: 검증된 초안을 기안문 표시 데이터로 변환
- `PrebudgetPage.tsx`: 입력, 저장, 복원, 검증, 미리보기 전환 관리
- `PrebudgetPreview.tsx`: K-에듀파인 복사용 화면 미리보기와 복사
- `exportWord.ts`, `exportPdf.ts`, `exportExcel.ts`: 파일 생성
- `prebudget.css`: 입력, 오류, 미리보기, 반응형·인쇄 스타일

기존 `src/domain/prebudget.ts`의 단위사업, 원가통계비목 설명, 금액 계산 함수는 재사용한다. 기존 `App.tsx`는 메뉴 이동과 페이지 연결만 담당하게 한다.

## 테스트와 검증

- 버튼에 클릭 동작이 연결되는지 검증한다.
- 학교명을 포함한 전체 초안이 저장되고 다시 열 때 복원되는지 검증한다.
- 학교명을 변경한 뒤 다시 저장하면 최신 초안의 학교명과 출력 파일명이 함께 변경되는지 검증한다.
- 손상된 저장 데이터에서 기본 초안으로 안전하게 복구하는지 검증한다.
- 완전히 빈 행이 검증·미리보기·출력에서 제외되는지 검증한다.
- 일부 입력 행과 필수 기본정보 오류가 정확히 안내되는지 검증한다.
- 자동점검 통과 후 기안문 내용과 총액이 정확한지 검증한다.
- 복사 버튼이 생성된 기안문 텍스트를 복사하는지 검증한다.
- Word·PDF·Excel 파일 생성 함수가 비어 있지 않은 파일을 반환하는지 검증한다.
- Excel 시트명, 표 머리글, 숫자 값과 합계를 검증한다.
- 전체 테스트와 TypeScript·Vite 빌드를 실행한다.

## 배포 원칙

- 수정과 검증 후 Vercel Preview로만 배포한다.
- 사용자가 Preview를 확인하고 별도로 승인하기 전에는 운영 배포, promote, 운영 도메인 연결을 실행하지 않는다.

## 완료 기준

- `임시저장` 버튼이 현재 브라우저에 초안을 저장하고 다시 열 때 복원한다.
- 사용자가 입력한 학교명이 저장·복원되고 기안문과 파일명에 반영된다.
- `자동점검 후 기안문 생성` 버튼이 빈 행을 제외하고 입력 오류를 안내한다.
- 검증을 통과하면 기안문 미리보기와 전체 복사가 동작한다.
- Word·PDF·Excel 파일을 내려받을 수 있다.
- 기존 20개 원가통계비목 설명 연동과 금액 계산 기능이 유지된다.
- 전체 테스트와 빌드가 통과한다.
- Vercel Preview에서 사용자 확인이 가능하다.

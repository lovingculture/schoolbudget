# yegamday 30초 홍보영상 설계

## 목적

교직원과 일반인에게 `학교예산 한눈에` 웹앱의 제작 계기와 주요 기능을 쉽고 친근하게 소개한다. 핵심 메시지는 “배우는 AI에서 일하는 AI로의 전환”이며, 학교예산 분석과 예산 관련 자료 제작을 실제 업무에 활용할 수 있다는 점을 30초 안에 전달한다.

## 기본 규격

- 길이: 약 30초
- 화면 비율: 16:9 가로형
- 대상: 교직원과 일반인
- 공개 주소: `https://yegamday.vercel.app`
- 표현 방식: 3D 자라나·열리미 캐릭터와 실제 웹앱 화면을 결합한 혼합형
- 음성 방식: 따뜻하고 신뢰감 있는 내레이션과 캐릭터 대사 혼합
- 분위기: 친근함, 신뢰감, 업무 효율성, 밝은 미래감

## 핵심 메시지

1. 반복적이고 복잡한 학교예산 업무의 부담을 줄이기 위해 만들었다.
2. AI는 설명만 하는 도구가 아니라 실제 업무를 돕는 도구로 전환되고 있다.
3. 학교별 예산과 결산 정보를 검색하고 한눈에 분석할 수 있다.
4. 파일을 드래그하면 예산 관련 문서와 Excel 자료를 간편하게 만들 수 있다.
5. 성립전예산, 본예산 기초자료, 안건설명서, 결산·추경 자료 등의 업무를 지원한다.

## 장면별 구성

### 1. 제작 계기 — 0~4초

- 화면: 책상 위에 서류와 표가 쌓여 있고 교직원이 난감해한다. 자라나와 열리미가 화면 양쪽에서 등장한다.
- 내레이션: “반복되는 학교예산 업무, 더 쉽고 빠르게 할 수 없을까요?”
- 자막: `복잡하고 반복적인 학교예산 업무`
- 연출: 차분한 회색빛에서 캐릭터 등장과 함께 색감이 밝아진다.

### 2. AI의 전환 — 4~8초

- 화면: 책 모양의 AI 아이콘이 빛나는 업무 도구 상자로 변하고, 자라나와 열리미가 `학교예산 한눈에` 화면의 문을 연다.
- 내레이션: “이제, 배우는 AI에서 실제로 일하는 AI로.”
- 자막: `배우는 AI에서, 일하는 AI로`
- 연출: 청록색 빛의 전환과 부드러운 줌인.

### 3. 학교예산 분석 — 8~13초

- 화면: `yegamday` 실제 웹앱에서 학교명을 검색하고 세입·세출·결산 분석 화면이 펼쳐진다. 자라나가 돋보기를 들고 결과를 가리킨다.
- 자라나: “학교를 검색하면 예산과 결산 흐름을 한눈에!”
- 자막: `학교별 예산·결산 분석`
- 연출: 검색 → 선택 → 분석 결과가 한 흐름으로 보이도록 빠르게 연결한다.

### 4. 예산자료 제작 — 13~18초

- 화면: 열리미가 Excel 파일을 드래그해 웹앱의 업로드 영역에 놓는다. 화면에서 문서와 Excel 아이콘이 완성되어 나온다.
- 열리미: “파일을 드래그하면 문서와 엑셀이 뚝딱!”
- 자막: `파일을 드래그하면 문서와 엑셀이 뚝딱!`
- 연출: 드래그 동작과 결과 생성 순간에 가벼운 반짝임 효과를 사용한다.

### 5. 지원 업무 소개 — 18~25초

- 화면: 성립전예산, 본예산 기초자료, 안건설명서, 결산, 추경 자료 카드가 차례로 나타난다. 각 카드는 실제 웹앱 디자인을 사용한다.
- 내레이션: “성립전예산부터 본예산, 안건설명서와 추경자료까지 간편하게.”
- 자막: `빠르게 · 정확하게 · 한눈에`
- 연출: 기능을 모두 읽게 하기보다 대표 카드와 아이콘을 빠르고 명확하게 보여준다.

### 6. 마무리 — 25~30초

- 화면: 자라나와 열리미가 웹앱 화면 앞에서 손을 흔든다. 로고와 주소가 중앙에 크게 표시된다.
- 자라나·열리미: “학교예산 업무의 든든한 파트너, 학교예산 한눈에!”
- 최종 자막: `yegamday.vercel.app`
- 연출: 로고와 주소는 마지막 2초 이상 고정해 읽을 시간을 확보한다.

## 캐릭터 연출

- 자라나: 파란색 계열의 3D 캐릭터. 적극적이고 자신감 있는 표정과 동작으로 분석 기능을 소개한다.
- 열리미: 노란색 계열의 3D 캐릭터. 친근하고 경쾌한 동작으로 파일 업로드와 자료 제작을 소개한다.
- 기존 캐릭터의 색상, 얼굴, 머리 형태와 전체 인상을 유지한다.
- 재질은 부드러운 3D 애니메이션 스타일로 표현하며 지나치게 사실적인 질감은 사용하지 않는다.
- 입 모양은 대사에 맞춰 자연스럽게 움직이고, 손과 눈동자의 움직임으로 화면의 주요 기능을 안내한다.

## 화면·자막·음향 기준

- 웹앱 화면은 `https://yegamday.vercel.app`의 실제 디자인과 기능명을 사용한다.
- 웹앱 화면의 개인정보나 실제 학교의 민감한 정보는 노출하지 않는다.
- 자막은 모바일에서도 읽을 수 있도록 굵고 큰 글씨로 표시한다.
- 한 장면의 핵심 자막은 한 줄 또는 두 줄 이내로 제한한다.
- 배경음악은 밝고 가벼운 디지털 리듬을 사용하되 대사를 방해하지 않는다.
- 효과음은 AI 전환, 검색 완료, 파일 드래그, 결과 생성 지점에만 짧게 사용한다.
- 장면 전환은 빠르되 번쩍임이나 과도한 카메라 회전은 피한다.

- 음성 포함 버전

## 완료 기준

- 전체 길이가 28~32초 범위에 들어간다.
- 제작 계기, AI의 전환, 학교예산 분석, 예산자료 제작, 웹주소가 모두 전달된다.
- 자라나와 열리미의 외형이 장면마다 일관된다.
- 웹앱 기능명과 화면이 실제 사이트와 일치한다.
- 교직원뿐 아니라 학교회계에 익숙하지 않은 일반인도 핵심 용도를 이해할 수 있다.
- 마지막 주소가 최소 2초간 선명하게 표시된다.

# 결산 안건설명서 문서 다운로드 설계

## 목표

결산 안건설명서 결과를 실제 편집 가능한 한글 HWPX와 Word DOCX, 인쇄용 PDF로 내려받을 수 있게 한다. 결과 Excel 다운로드는 제거하되, 에듀파인 원본자료 업로드는 `.xls`와 `.xlsx`를 모두 계속 지원한다.

## 사용자 화면

결산 안건설명서의 다운로드 영역에는 다음 버튼만 표시한다.

1. 한글(HWPX)
2. Word(DOCX)
3. PDF

각 버튼에는 확장자를 명시한다. 생성 중에는 해당 버튼을 비활성화하고 진행 표시를 보여준다. 실패 시 어떤 형식의 생성이 실패했는지 안내한다. 기존 결과 Excel 버튼은 제거한다.

## 공통 문서 내용

세 형식에는 화면에서 사용자가 수정한 최신 초안 값을 사용한다.

- 학교명과 학년도
- 안건번호, 제안연월일, 제안자, 제안설명자
- 제안이유, 근거, 주요내용
- 세입·세출 결산 총괄 금액
- 세입 결산내역과 세출 결산내역
- 천 단위 콤마와 원 단위 표기
- A4 기준 제목, 문단, 표, 페이지 나눔

화면과 각 다운로드 파일의 금액은 동일해야 한다.

## 형식별 구현

### HWPX

브라우저 내부에서 HWPX 표준 ZIP/XML 패키지를 생성한다. 확장자만 바꾼 파일이나 HTML을 HWPX로 위장하지 않는다. 최소 필수 패키지 항목, 메타데이터, 글꼴/스타일 정의, 문단, 표, 페이지 설정을 포함한다. 생성 결과는 ZIP 엔트리와 핵심 XML을 자동 검사하고 Preview에서 실제 한글 프로그램으로 열기 검증을 수행한다.

### DOCX

기존 `docx` 기반 생성기를 유지·보완한다. 문서 속성, A4 여백, 제목과 본문, 표 구조, 정렬, 숫자 형식을 HWPX와 동일한 초안 데이터에서 만든다. DOCX ZIP 내부의 `word/document.xml`에 핵심 문구와 금액이 들어 있는지 검사한다.

### PDF

현재 A4 미리보기 요소를 PDF로 변환하는 방식을 유지한다. 미리보기 두 쪽의 순서와 화면 수정값이 반영되고 A4 페이지 크기가 유지되는지 검사한다.

## 개인정보 및 데이터 흐름

엑셀 분석과 HWPX·DOCX·PDF 생성은 모두 브라우저에서 수행한다. 업로드 자료나 생성 문서를 외부 변환 서버로 보내지 않는다.

## 제거 범위와 호환성

- 결산 결과 Excel 버튼, 결산 Excel 생성 모듈, 전용 테스트를 제거한다.
- `.xls`와 `.xlsx` 업로드 파서 및 안내 문구는 변경하지 않는다.
- 추경자료·본예산 등 다른 화면의 Excel 다운로드는 변경하지 않는다.
- 기존 PDF 및 Word 다운로드 동작은 회귀 테스트로 보호한다.

## 오류 처리

각 생성기는 실패 원인을 호출부로 전달하고 화면에는 `한글(HWPX) 파일을 만들지 못했습니다`처럼 형식이 드러나는 안내를 표시한다. 실패한 형식 외의 다운로드 버튼은 계속 사용할 수 있어야 한다.

## 검증 기준

- 결산 다운로드 영역에 HWPX, DOCX, PDF 버튼만 표시된다.
- 결과 Excel 버튼과 결산 Excel 생성 코드가 제거된다.
- `.xls`, `.xlsx` 업로드 테스트가 모두 통과한다.
- HWPX가 유효한 ZIP 패키지이며 필수 파일과 초안의 핵심 값이 포함된다.
- DOCX가 유효한 문서 패키지이며 핵심 값이 포함된다.
- PDF가 A4 두 쪽으로 생성된다.
- 실제 제공된 결산 `.xlsx`의 금액이 세 결과물과 일치한다.
- 한글 프로그램에서 HWPX가 열리고 편집 가능함을 Preview에서 확인한다.
- 전체 테스트와 빌드가 통과한다.
- Production에는 별도 승인 전까지 배포하지 않는다.

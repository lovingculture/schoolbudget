# 집행실적으로 추경자료 만들기 설계

## 목적

K-에듀파인에서 내려받은 집행실적 엑셀저장(실시간) 자료코드 102-2 파일을 웹앱에 드래그하면, 사용자가 추경 검토자료를 웹에서 확인·수정하고 하나의 Excel 파일로 내려받는다.

## 메뉴

- 본예산의 준비 중 표시는 유지한다.
- 예산안건 설명서와 결산설명서의 준비 중 표시는 제거한다.
- 집행실적으로 추경자료 만들기 메뉴를 추가한다.

## 업로드 안내

화면에 다음 경로를 표시한다.

> K-에듀파인 학교회계 → 사업관리 → 사업관리카드 → 집행실적 엑셀저장(실시간)으로 이동한 후, 자료코드 102-2를 선택하여 내려받은 엑셀 파일을 넣어주세요.

드롭 영역에는 에듀파인 집행실적 엑셀(실시간) 102-2 파일을 여기에 끌어다 놓으세요.를 표시한다. 사용자가 제공한 K-에듀파인 화면을 참고 이미지로 열어볼 수 있게 한다.

## 입력 검증

- xlsx, xls, xlsm 파일만 허용한다.
- 첫 번째 시트에서 머리글 행을 이름으로 탐색한다.
- 파일명만 믿지 않고 회계연도, 집행일자, 학교명, 정책사업, 단위사업, 세부사업, 세부항목, 목명, 세목명, 원가통계비목명, 산출내역, 예산액(4), 원인행위금액(17), 지출금액(18)의 존재로 102-2 형식을 판정한다.
- 실패하면 에듀파인 실시간 집행실적 102-2 파일을 넣어주세요.와 다운로드 경로를 안내한다.
- 성공하면 회계연도, 학교명, 집행기준일, 자료 행 수를 표시한다.

## 원본 매핑

열 문자를 고정하지 않고 머리글 이름으로 읽는다. 제공 파일의 현재 위치는 정책사업 N, 단위사업 P, 세부사업 R, 세부항목 T, 목명 V, 세목명 X, 원가통계비목명 Z, 산출내역 AA, 예산액(4) AE, 원인행위금액 AR, 지출금액 AS이다.

## 계산

모든 핵심 계산은 사용자가 확정한 예산액(4)을 기준으로 하며 예산현액(16)은 기준으로 쓰지 않는다.

- 집행잔액 = 예산액(4) - 원인행위금액
- 원인행위·지출 불일치 = 원인행위금액 - 지출금액
- 집행률 = 원인행위금액 / 예산액(4) × 100
- 예산액이 0원이면 집행률은 0%이다.
- 추경 가능금액 = 집행잔액 - 부서별 집행예정액
- 부서별 집행예정액과 추경(안)은 사용자가 수정한다.
- 합계와 집계는 현재 필터 결과에 맞춰 계산한다.

## 웹 화면

안내와 파일 드롭 영역, 업로드 요약, 예산집행현황·단위사업 집계·추경검토자료·추경검토안 전환 탭, 검색·필터·정렬·합계, 사용자 입력 열, 초기화와 Excel 다운로드를 제공한다. 금액에는 천 단위 구분기호를 적용하고 음수는 빨간색으로 표시한다. 긴 표에는 고정 머리글과 가로 스크롤을 제공한다.

## 결과 자료

- 예산집행현황: 식별 열, 예산액, 원인행위, 지출, 집행잔액, 불일치, 집행률
- 단위사업 집계: 정책사업·단위사업별 예산액, 원인행위, 지출, 집행잔액, 집행률
- 추경검토자료: 위 자료에 부서별 집행예정액, 추경 가능금액, 추경(안) 추가
- 추경검토안: 상세 식별 열과 위 금액을 표시하고 상단에 전체 합계와 일반업무추진비 소계 제공

## Excel 다운로드

하나의 xlsx 파일에 불러온원본, 추경검토자료, 예산집행현황, 단위사업 집계, 추경검토안 순서로 시트를 만든다. 원본은 값으로 보존하고 결과 시트에는 필터, 고정 머리글, 합계, 금액·집행률 서식, 음수 빨간색 표시를 적용한다. 웹에서 입력한 값도 반영한다.

## 오류와 안전

브라우저 안에서 파일을 분석하며 K-에듀파인 로그인이나 전자결재 제출은 하지 않는다. 필수 열 누락, 빈 파일, 읽기 실패를 구분한다. 새 파일 업로드나 초기화 전에 사용자 입력이 있으면 확인한다. 원본 행 순서와 텍스트를 보존한다.

## 테스트

실제 제공된 102-2 파일 파싱, 필수 열 누락 거부, 0원·음수·불일치 계산, 단위사업 합계, 사용자 입력 재계산, 메뉴 배지와 이동, Excel 시트명·순서·핵심 값, 프로덕션 빌드, 배포 후 HTTP 200을 검증한다.

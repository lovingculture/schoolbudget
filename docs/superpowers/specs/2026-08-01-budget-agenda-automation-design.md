# 예산 안건설명서 자동화 설계

## 1. 목적

기존 학교예산 포털의 `예산안건 설명서` 메뉴를 실제 자동화 기능으로 전환한다. 사용자가 K-에듀파인 예산현황에서 내려받은 `세입 세출 예산 총괄` Excel 파일을 올리면 예산 총괄 내용을 자동 분석하고, 수정 가능한 입력 화면과 공식 안건설명서 미리보기를 제공한다.

첨부된 다음 세 파일을 기준 자료로 사용한다.

- `000(1).xlsx`: K-에듀파인 원본 예산 총괄표
- `예산안건설명서 자동화(2).xlsm`: 기존 사용 흐름과 안내 문구
- `2026학년도 서울옥정초등학교 회계 1차 추경예산(안).pdf`: 최종 문서의 내용과 A4 배치

## 2. 사용자 흐름

1. 사용자가 왼쪽 메뉴에서 `예산안건 설명서`를 선택한다.
2. 업로드 화면에 아래 안내를 표시한다.
   - 에듀파인 예산현황의 세입세출총괄표를 다운로드한 후 `세입세출총괄표 불러오기` 버튼을 눌러 원본 파일을 선택하세요.
   - 자동으로 만들어지는 입력 화면에서 안건번호, 제안이유, 근거, 주요내용 등을 수정하세요.
3. 사용자가 버튼 또는 드래그 앤 드롭으로 Excel 파일을 올린다.
4. 브라우저가 파일을 분석하고 자동 입력값, 검증 결과, A4 미리보기를 만든다.
5. 사용자가 입력값과 자동 추출된 표를 수정한다.
6. 사용자가 PDF, Word 또는 일반 Excel 파일을 내려받는다.

파일 분석과 문서 생성은 브라우저에서 처리하며 업로드한 예산자료를 외부 데이터베이스에 저장하지 않는다.

## 3. 원본 파일 분석

### 3.1 지원 파일

- `.xlsx`, `.xls`
- 시트명 또는 시트 내용에서 `세입 세출 예산 총괄` 양식을 식별한다.
- 지원하지 않는 파일에는 `에듀파인 예산현황의 세입세출예산총괄 파일인지 확인해 주세요.`를 표시한다.

### 3.2 자동 추출 항목

- 회계연도
- 학교명
- 예산구분: 본예산 또는 추경 차수
- 경정예산액
- 기정예산액
- 비교증감액
- 증감률
- 세입: 장, 관, 금회, 누계, 구성비
- 세출: 정책사업, 금회, 누계, 구성비

셀 위치를 고정하지 않고 제목과 열 머리글을 찾아 값을 읽는다. 행 수가 달라져도 합계 전까지 유효한 항목을 수집한다.

## 4. 자동 작성 규칙

### 4.1 문서 제목

- 본예산: `{회계연도}학년도 {학교명} 회계 본예산(안)`
- 추경: `{회계연도}학년도 {학교명} 회계 {차수}차 추경예산(안)`

### 4.2 기본 입력값

- 안건번호: 빈 값
- 제안연월일: 빈 값
- 제안자: `학교장`
- 제안설명자: `행정실장`
- 제안이유: `{회계연도}학년도 학교회계 {예산구분}예산을 심의 받고자 함`
- 근거:
  - `가. 「초·중등교육법」 제30조의3(학교회계의 운영), 제32조(심의·자문사항)`
  - `나. {회계연도}학년도 학교회계 예산편성 기본지침`
- 추경예산 편성 주요내용: 사용자가 직접 입력하는 빈 행 2개

본예산일 때에는 화면과 출력 문서에서 `추경예산 편성 주요내용`을 `예산 편성 주요내용`으로 표시한다.

## 5. 편집 화면

편집 화면은 기존 결산 설명서와 같은 두 영역으로 구성한다.

- 왼쪽: 입력·수정 영역
- 오른쪽: 실시간 A4 문서 미리보기

수정 가능 항목:

- 문서 제목, 안건번호, 제안연월일, 제안자, 제안설명자
- 제안이유, 근거, 예산 편성 주요내용
- 총 규모 금액과 증감률
- 세입·세출 항목명, 금액, 구성비, 비고

금액 입력창과 미리보기에는 세 자리마다 쉼표를 표시한다. 자동 추출된 숫자가 변경되면 `수정됨`을 표시하고 `원본값` 버튼으로 복원할 수 있게 한다.

## 6. 미리보기와 출력 문서

제공된 최종 PDF를 기준으로 A4 세로 2쪽을 기본 배치로 한다.

### 1쪽

- 문서 제목
- 안건번호와 제안 정보
- 1. 제안이유
- 2. 근거
- 3. 주요내용
- 가. 총 규모
- 나. 세입예산
- 다. 세출예산의 첫 부분

### 2쪽

- 세출예산의 나머지 행
- 합계
- 라. 예산 편성 주요내용

세입·세출 행 수가 기준보다 달라지면 표를 잘라 숨기지 않고 다음 페이지로 자연스럽게 넘긴다. 모든 표의 단위는 `천원`이며 숫자는 오른쪽 정렬과 천 단위 구분을 적용한다.

## 7. 다운로드

- PDF: 화면의 A4 미리보기와 같은 배치
- Word: 제목, 제안정보, 본문, 세입·세출 표를 편집 가능한 문서로 생성
- 일반 Excel: 매크로 없는 `.xlsx` 파일이며 `입력` 시트와 `안건설명서` 시트를 포함

파일명은 `{회계연도}학년도_{학교명}_{예산구분}_예산안건설명서`를 기본으로 한다.

## 8. 검증과 오류 처리

- 경정예산액 - 기정예산액 = 비교증감액
- 세입 금회 합계와 세출 금회 합계가 비교증감액과 일치
- 세입 누계 합계와 세출 누계 합계가 경정예산액과 일치
- 세입·세출 구성비 합계가 반올림 오차 범위에서 100%인지 확인

검증 결과는 업로드 직후 표시한다. 불일치가 있어도 원본 파일의 특수한 구조일 수 있으므로 편집은 허용하되, 내려받기 전에 확인 경고를 표시한다. 손상 파일, 빈 파일, 다른 보고서는 명확한 오류 문구로 거절한다.

## 9. 코드 구성

`src/features/budgetAgenda/`에 기능을 분리한다.

- `types.ts`: 원본 데이터, 편집 초안, 검증 결과 형식
- `parser.ts`: 에듀파인 Excel 분석
- `createDraft.ts`: 자동 문구와 편집 초안 생성
- `validation.ts`: 합계와 증감 검증
- `BudgetAgendaPage.tsx`: 업로드부터 편집·미리보기까지 전체 상태
- `BudgetAgendaEditor.tsx`: 사용자 입력
- `BudgetAgendaPreview.tsx`: A4 미리보기
- `BudgetAgendaDownloads.tsx`: PDF·Word·Excel 출력
- `exportPdf.ts`, `exportWord.ts`, `exportExcel.ts`: 파일 생성

기존 결산 설명서의 금액 입력, 다운로드 상태, A4 미리보기 패턴을 재사용하되 예산 안건설명서의 데이터와 문서 규칙은 독립 모듈로 유지한다.

## 10. 테스트

- 제공된 `000(1).xlsx`에서 학교명, 회계연도, 예산구분, 총액, 세입·세출 행을 정확히 추출
- 본예산과 추경 제목 및 기본 문구 생성
- 합계·증감·구성비 검증
- 잘못된 파일과 손상 파일 오류
- 모든 편집 항목의 화면 반영
- 천 단위 쉼표 입력과 원본값 복원
- A4 미리보기 핵심 문구와 표 렌더링
- PDF·Word·Excel 파일 생성과 기본 내용 확인
- 기존 결산 설명서 및 추경자료 기능 회귀 테스트

## 11. 완료 조건

- 제공된 원본 파일로 예시 PDF와 같은 내용의 안건설명서를 생성한다.
- 사용자가 요청한 설명 문구가 업로드 화면에 표시된다.
- 모든 핵심 문구와 표를 웹에서 수정할 수 있다.
- PDF, Word, 일반 Excel 다운로드가 모두 동작한다.
- 기존 포털 기능과 테스트가 유지된다.
- 미리보기 배포에서 사용자가 검토한 뒤 별도 승인 시에만 운영 배포한다.

# 본예산 세출 요구자료 통합·검토 초기 버전 설계

## 목표

학교 각 부서가 작성한 본예산 세출 요구자료 `.xls`·`.xlsx` 파일만 여러 개 업로드하고, 자료를 통합해 오류와 확인 필요 항목을 검토할 수 있게 한다. 세입자료는 부서별 취합 대상이 아니므로 세출과 섞지 않고 별도 탭에서 업로드한다. 업무추진비 3% 한도는 별도 세입자료와 통합된 세출자료를 연결해 계산한다.

## 본예산 화면 구조

본예산 화면은 다음 두 탭으로 분리한다.

1. `세출자료 통합·검토`: 부서별 세출 요구자료 여러 파일을 업로드하고 통합·검토한다.
2. `세입자료·3% 검토`: 학교 전체 세입자료를 별도로 업로드하고 업무추진비 한도를 계산한다.

두 탭의 파일과 처리 상태는 분리해 저장한다. 세입파일이 없어도 세출 업로드·통합·검토·다운로드는 모두 정상 작동한다. 세출 통합 결과가 없거나 세입파일이 없으면 3% 탭은 계산값을 추측하지 않고 필요한 자료를 안내한다.

## 기준 표본

초기 파서는 `budget.xls`의 `세출예산서식` 구조를 기준으로 한다.

| 순서 | 열 |
|---|---|
| 1 | 부서명 |
| 2 | 세부사업명 |
| 3 | 세부항목명 |
| 4 | 원가통계비목명 |
| 5 | 산출내역 |
| 6 | 산출식 |
| 7 | 요구금액 |
| 8 | 사업담당자 |
| 9 | 전년산출식 |
| 10 | 전년요구금액 |
| 11 | 증감 |

정확한 시트명이 달라도 위 열 제목 조합을 탐색해 입력표를 찾는다. 확장자만 믿지 않고 실제 파일 형식과 통합문서 구조를 검사한다.

## 수식 처리 원칙

표본의 요구금액과 증감에는 VBA 사용자 정의 함수 `calstr`와 `CalMinus`가 들어 있다. 브라우저는 VBA를 실행하지 않으므로 원본의 `#NAME?` 또는 캐시값을 확정값으로 사용하지 않는다.

- 요구금액은 산출식을 안전한 자체 계산기로 해석해 계산한다.
- 증감은 `요구금액 - 전년요구금액`으로 계산한다.
- 숫자, 천 단위 쉼표, 원·명·개·회·월 등 단위와 `×`, `x`, `X`, `*`, 괄호로 표현된 기본 산출식을 지원한다.
- 임의 코드 실행을 막기 위해 `eval`이나 동적 함수 실행은 사용하지 않는다.
- 해석할 수 없는 산출식은 금액을 추측하지 않고 `확인 필요`로 표시한다.
- 원본에 정상 숫자 요구금액이 있고 산출식도 계산되면 두 값을 비교해 불일치를 표시한다.

## 세출자료 통합·검토 탭 사용자 흐름

1. 본예산 메뉴의 `세출자료 통합·검토` 탭에서 부서별 `.xls`·`.xlsx` 파일을 여러 개 선택한다.
2. 각 파일의 형식, 시트, 제목 행과 데이터 범위를 자동 탐색한다.
3. 파일별 부서명, 인식 행 수, 원본 합계, 오류 상태를 보여준다.
4. 정상 행을 공통 데이터 구조로 통합하고 산출식·요구금액·증감을 계산한다.
5. 상단 요약과 통합표에서 결과를 검토한다.
6. 검색·필터·정렬로 오류나 특정 부서·사업만 확인한다.
7. 통합본과 오류검토 보고서를 `.xlsx`로 내려받는다.

## 공통 데이터 구조

각 통합 행에는 원본 파일명, 원본 시트명, 원본 행 번호와 11개 업무 열을 보관한다. 계산된 요구금액과 증감, 원본 요구금액, 검토 상태, 검토 메시지도 별도로 보관해 원본과 계산 결과를 추적할 수 있게 한다.

검토 수준은 다음 세 가지다.

- 오류: 필수 구조가 없거나 계산상 명백한 불일치
- 주의: 중복 또는 비정상 금액처럼 담당자 판단이 필요한 경우
- 확인 필요: 산출식을 안전하게 해석하지 못했거나 분류 기준이 부족한 경우

자동분석은 확정 판정으로 표시하지 않는다.

## 세출 자동검토

- 필수 열 또는 필수값 누락
- 산출식 해석 실패
- 산출식 계산액과 원본 요구금액 불일치
- 요구금액과 전년요구금액의 증감 불일치
- 같은 부서·세부사업·세부항목·산출내역의 중복 의심
- 0원, 음수 또는 비정상적으로 큰 단가·수량·금액
- 원가통계비목 누락
- 파일별 원본 합계와 통합 합계 불일치

원가통계비목의 정책적 적합성은 기준표가 확보되기 전까지 누락과 명칭 확인 수준으로 제한한다.

## 화면

상단에는 전체 요구액, 전년 요구액, 증감액, 인식 부서 수, 정상·오류·주의·확인 필요 건수를 표시한다. 그 아래에 파일별 처리 현황과 통합표를 둔다.

통합표는 부서, 세부사업, 세부항목, 원가통계비목, 검토 상태 필터와 통합검색, 열 정렬, 고정 헤더, 현재 조회 건수와 필터 합계를 제공한다. 대용량 자료는 페이지당 표시 건수를 제한해 화면 정지를 방지한다.

업로드된 자료와 편집 상태는 브라우저 내부 임시저장만 사용한다. 세출 초기화는 세출자료에만 적용하고 확인창을 표시한다.

## 다운로드

- 부서별 통합본 `.xlsx`: 원본 식별정보, 업무 열, 계산 결과와 검토 상태 포함
- 오류검토 보고서 `.xlsx`: 수준, 부서, 사업, 원본 위치, 문제, 판단 근거, 권장 확인사항 포함

화면 합계와 다운로드 합계는 같은 통합 데이터와 계산 함수를 사용한다.

## 세입자료·3% 검토 탭

세입자료는 `세입자료·3% 검토` 탭에서 학교 전체 자료를 별도로 업로드한다. 이 탭은 부서별 세출 파일을 받지 않으며, 세입 표본을 받은 뒤 실제 시트·열 구조에 맞는 파서를 추가한다.

업무추진비 한도 계산은 세입자료의 학교운영경비 산정 기준액과 세출 통합자료의 업무추진비 요구액을 연결한다. 결과에는 편성 한도, 현재 요구액, 잔여 한도 또는 초과액과 검토 상태를 표시한다.

산정식은 제공된 기준에 따라 `학교운영경비 × 3%`를 사용한다. 학교운영경비는 세입예산총액에서 목적사업비전입금, 수익자부담수입 등 제외 대상을 실제 세입자료의 항목과 연결해 계산한다. 정확한 포함·제외 항목은 제공될 세입 표본과 예산편성지침을 대조해 확정한다.

세입파일이나 세출 통합 결과 중 하나라도 없으면 3% 결과를 표시하지 않고 `세입자료 필요` 또는 `세출 통합자료 필요`로 안내한다. 항목 연결이 불완전하면 한도 초과를 확정하지 않고 `산정자료 확인 필요`로 표시한다. 세입 초기화는 세출자료에 영향을 주지 않는다.

## 오류 처리

- 암호화·손상·지원하지 않는 파일은 파일별로 이해하기 쉬운 오류를 표시하고 다른 파일 처리는 계속한다.
- 필요한 표를 찾지 못하면 탐색한 시트와 누락된 열을 안내한다.
- 빈 양식은 정상 파일로 인식하되 `입력 자료 없음`으로 표시한다.
- 일부 행만 잘못된 경우 정상 행은 유지하고 잘못된 행만 검토 대상으로 남긴다.

## 테스트 기준

- `.xls`와 `.xlsx` 표본 업로드
- 여러 파일 동시 업로드와 파일별 실패 격리
- 제목 행·시트명 자동 탐색
- VBA `#NAME?`가 있어도 자체 계산 계속
- 지원 산출식 계산과 비지원 산출식의 `확인 필요` 처리
- 요구금액·증감 불일치 검출
- 누락·중복·비정상 금액 검토
- 파일별 합계, 통합 합계, 필터 합계, 다운로드 합계 일치
- 잘못된 파일과 빈 양식 오류 안내
- 임시저장·초기화 확인
- 기존 결산·추경·성립전예산·안건설명서 기능 회귀테스트

## 제외 범위

이번 세출 초기 빌드에는 세입 파싱과 업무추진비 3% 확정 계산을 포함하지 않는다. 다만 본예산 화면의 별도 `세입자료·3% 검토` 탭 구조와 자료 미등록 안내를 마련해 세입 표본 수령 후 파서를 연결할 수 있게 한다. 지침 페이지 연결, 전년도 자동 사업 매칭, 3가지 조정 시나리오, HWPX·PDF 본예산 안건설명서도 후속 범위다.

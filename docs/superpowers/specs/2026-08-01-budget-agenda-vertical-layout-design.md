# 예산 안건설명서 세로형 화면 설계

## 목표

예산 안건설명서의 입력 화면과 A4 미리보기를 결산 안건설명서처럼 위에서 아래로 이어지는 한 개 열로 표시한다.

## 화면 구조

파일을 불러온 뒤 `자동 검증 → 입력 영역 전체 → A4 미리보기 → 내려받기` 순서로 표시한다. 제안정보, 총 규모, 세입·세출 내역, 주요내용은 현재 순서와 기능을 유지하며 페이지 전체 폭을 사용한다. 모든 입력 영역 아래에서 A4 미리보기가 시작되고, 미리보기 문서는 가운데 정렬한다.

## 변경 범위

- `.budget-agenda-workspace`를 모든 데스크톱 화면에서 한 개 열로 고정한다.
- 기존 1500px 반응형 전환에 의존하지 않도록 한다.
- 파일 파싱, 입력값 수정, 자동 검증, A4 출력, PDF·Word·Excel 다운로드 동작은 변경하지 않는다.
- 모바일 화면의 기존 세로 배치를 유지한다.

## 검증

- 페이지 렌더링 테스트에서 작업공간이 세로형 레이아웃 전용 클래스/구조를 사용하는지 확인한다.
- 예산 안건설명서 단위 테스트와 전체 빌드를 실행한다.
- Vercel Preview 배포 후 배포 상태를 확인한다.
